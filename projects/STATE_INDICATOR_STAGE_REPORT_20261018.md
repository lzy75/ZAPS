# 状态感知指标研究阶段报告

日期：2026年10月18日。主题：从跨图相关性验证，推进到单图引导方向及局部敏感度。

## 1. 阶段结论

已经完成双指标定义、20图相关性验证、采样注噪对照、clean余弦替代比较、
多代控制映射，以及成功重建单图完整轨迹的被动观察与条件均值分解。
现有证据支持物理残差作为主要过程读数，支持保留方向几何作为辅助候选，
尚未证明现有余弦能可靠指导在线控制并带来综合重建收益。

本阶段收敛的三个判断是：

1. 末步残差与最终PSNR在已测试FFHQ子集上有强负相关；这不等于残差越小
   感知质量一定越好，也不等于该信号已经在独立图像和任务上泛化。
2. clean余弦比含噪余弦在部分统计中关联更强，但符号、聚合方式和阶段依赖
   尚不稳定；“余弦高=重建好”“负余弦=有害震荡”均未成立。
3. 实际测量引导方向已完成沿轨迹变化与固定时间敏感度的分开测量；三图双seed
   六条均有30/30有效q、5/5可读且有限尺度下降快照，跨样本可测性H1通过。
   六条在五个探测点中单位位移响应都以t319最高。同t的Omega3–该敏感度在五点两尺度
   均为负秩相关；A2b0按实际状态路径长度归一化后也未形成全阶段正向关系，
   当前不支持简单敏感度代理。增量辅助信息和细步收益仍未验证。

**本报告没有新增GPU重建收益。** 10月18日已重新计算历史归档相关性，A1a缓存
诊断和A1b敏感度探针均由用户回传通过；现已拉取711da42，完成单图阶段文本/曲线
归档审计。六个CSV存在可精确还原的换行转换，张量仍在服务器。两者均未生成
更优重建。[归档审计](STATE_INDICATOR_ARCHIVE_AUDIT_20261018.md)，状态边界见§8。

## 2. 问题与指标演进

开题中的状态体系希望由物理一致性和轨迹稳定性共同描述重建过程。当前更准确
的工作假设是：物理残差衡量“是否解释观测”，方向状态衡量“修正方向是否在当前
噪声阶段持续快速变化或反复回摆”。后者只有在能提供额外信息、并预测有益干预时，
才可成为控制依据，而不只是过程可视化。

| 指标 | 实际比较对象 | 当前证据定位 |
| --- | --- | --- |
| 物理残差 | ||y-A(z_k)||，z为原clamp后的Tweedie估计 | 主要过程读数，非完整画质指标 |
| 含噪增量余弦 | 相邻x_next-x_input | 含当步注噪，历史验证较弱 |
| clean增量余弦 | d_k=z_k-z_(k-1)，cos(d_k,d_(k-1)) | 原辅助候选，至少需要3个clean点 |
| 条件均值余弦 | 相邻posterior_mean+q-x_input | 去掉当步新噪声，仍依赖历史随机输入；未优于clean |
| priorGuideCos | 同一步posterior_mean-x与q | 组成诊断，不能代替相邻步余弦 |
| 新A1a引导余弦 | 相邻实际q方向 | 用户回传门控通过，有阶段结构但未获控制证据 |
| 新A1b局部敏感度 | 固定t/参数，在x±ηq处重算引导方向 | 五点两尺度可读且下降；不等于控制收益 |

所有方向指标先在全像素RGB空间测量。没有已确认的新多尺度/高频余弦收益。
物理观测噪声sigma_y=.05与扩散sigma_eff不同，报告中不混用。

## 4. 控制实验走过的路径

### 4.1 早期v1–v3：机制修复，尚无可靠综合优势

旧日志记录v1在SR20图平均dPSNR=-3.64、dSSIM=-.096、dLPIPS=+.070。
时间轨迹显示高噪声区消耗大量小步，末段停在t=120；绝对残差随噪声级变化、
