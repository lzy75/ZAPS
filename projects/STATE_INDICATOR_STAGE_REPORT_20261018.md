# 状态感知指标研究阶段报告

日期：2026年10月18日。主题：从跨图相关性验证，推进到单图引导方向及局部敏感度。

## 1. 阶段结论

已经完成双指标定义、20图相关性验证、采样注噪对照、clean余弦替代比较、
多代控制映射，以及成功重建单图完整轨迹的被动观察与条件均值分解。
现有证据支持物理残差作为主要过程读数，支持保留方向几何作为辅助候选，
尚未证明现有余弦能可靠指导在线控制并带来综合重建收益。

本阶段收敛的三个判断是：

1. 末步残差与最终PSNR在已测试FFHQ子集上有强负相关；这不等于残差越小
   感知质量一定越好，也不等于该信号已经在独立图像和任务上泛化。
2. clean余弦比含噪余弦在部分统计中关联更强，但符号、聚合方式和阶段依赖
   尚不稳定；“余弦高=重建好”“负余弦=有害震荡”均未成立。
3. 下一步观察对象改为实际测量引导修正方向；把沿轨迹的方向变化与固定时间
   的输入敏感度分开验证，最后才检验局部细步的重建收益。

**本报告没有新增GPU重建结果。** 10月18日已重新计算历史归档相关性，并实现
A1a缓存诊断入口；本机合同/几何检查与服务器数值执行的状态见§8。

## 2. 问题与指标演进

开题中的状态体系希望由物理一致性和轨迹稳定性共同描述重建过程。当前更准确
的工作假设是：物理残差衡量“是否解释观测”，方向状态衡量“修正方向是否在当前
噪声阶段持续快速变化或反复回摆”。后者只有在能提供额外信息、并预测有益干预时，
才可成为控制依据，而不只是过程可视化。

| 指标 | 实际比较对象 | 当前证据定位 |
| --- | --- | --- |
| 物理残差 | ||y-A(z_k)||，z为原clamp后的Tweedie估计 | 主要过程读数，非完整画质指标 |
| 含噪增量余弦 | 相邻x_next-x_input | 含当步注噪，历史验证较弱 |
| clean增量余弦 | d_k=z_k-z_(k-1)，cos(d_k,d_(k-1)) | 原辅助候选，至少需要3个clean点 |
| 条件均值余弦 | 相邻posterior_mean+q-x_input | 去掉当步新噪声，仍依赖历史随机输入；未优于clean |
| priorGuideCos | 同一步posterior_mean-x与q | 组成诊断，不能代替相邻步余弦 |
| 新A1a引导余弦 | 相邻实际q方向 | 已实现，服务器数值结果待回传 |
| 新A1b局部敏感度 | 固定t/参数，在x±ηq处重算引导方向 | 仅有预注册设计，未实现/运行 |

所有方向指标先在全像素RGB空间测量。没有已确认的新多尺度/高频余弦收益。
物理观测噪声sigma_y=.05与扩散sigma_eff不同，报告中不混用。

## 4. 控制实验走过的路径

### 4.1 早期v1–v3：机制修复，尚无可靠综合优势

旧日志记录v1在SR20图平均dPSNR=-3.64、dSSIM=-.096、dLPIPS=+.070。
时间轨迹显示高噪声区消耗大量小步，末段停在t=120；绝对残差随噪声级变化、
预算端点约束不足是明确问题。v2通过基础调度和有界调制将差距缩至约-.57dB，
后续又处理统一代价与ζ索引/轨迹同步。8月17日进一步定位优化eta=0与额外
采样eta=1的割裂，后续转向全程eta=1、直接返回last_opt。

这些结果是历史排错证据，不与修正后基线混算。旧日志“统计等价”“固定调度近乎
最优”缺少等价检验/最优性证明，本报告不沿用；准确表述是已测配置中未见可靠
综合优势。实现修复也不能代替方法收益。

## 7. 新验证路线及当前边界

主观察q为原ZAPS实际测量引导修正，真实clean空间g_z由实际A.H的VJP计算，
不使用经验transpose冒充真实梯度。二者各自形成时间序列，原clean余弦保留。
A1a新增相邻方向余弦、方向变化/Δu、最近三方向累计变化密度、回摆比例，
以及q、q/ζ、先验、条件均值、随机增量的RMS；不合成任意控制总分。

固定时间探针A1b将沿x±ηq在原t/参数下重算网络，区分输入敏感度与时间/参数
变化，并用实际复合损失的中央差分判断局部下降性质。计划5快照×6=30诊断NFE。
本次尚未实现/运行A1b，须先检查A1a身份和读数。

最后再检查相同起终点的粗细步收益。当前q没有显式Δu因子，直接重复子步会
改变累计引导；需事先规定子步ζ预算、D映射和符合DDPM的噪声耦合，不能把
独立噪声两条路径的差异当离散误差。这一阶段没有运行，正式网格保持原样。
