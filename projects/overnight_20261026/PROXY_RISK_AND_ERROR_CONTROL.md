# 代理风险与数值误差：第三轮方法核查

核查日期：2026-10-26。文献中的保证只在其假设下成立；本项目没有据此获得无偏风险或收敛保证。

## 1. SURE不能直接补上A48的局部目标缺口

[SGPS v1](https://arxiv.org/html/2512.23232v1)（2025-12-29预印本；当前记录未核实正式接收）
在DAPS式条件Langevin之后估计残留噪声，以PCA噪声估计与Monte Carlo散度构造SURE，
再作梯度修正并重新加噪。已核读§3.1、Algorithm1、§4.1及附录成本表。
它不是仅用测量残差选择现有q倍率。§4.1明确每外步3次denoiser：
主预测1次，SURE所需2次；另有100步条件Langevin和PCA/梯度的时间成本。

其定理3.1预设进入估计近似各向同性Gaussian、似然局部Lipschitz和小Langevin步；
定理3.2另要求局部强凸、光滑、SURE修正近似后验梯度且偏差/方差受控。
式19含正误差项，不能据此推出任意状态每次更新都严格减少KL。
这些条件在当前clamp、learned D、条件引导轨迹上未经验证。
原文的数值效果可以提示验证方向，不能使普通局部J自动变成终局MSE。

**本轮不新开第三条SURE控制线。** 先保留为“代理质量估计的适用条件”文献，
避免用一个名字更强的局部目标重复A48。若未来采用，必须新卡验证残差分布/尺度、
散度估计噪声与额外调用、终局预测能力及同成本参照，不只降低SURE本身。

## 2. GSURE不能无条件观察SR/修补的不可见区域

[Eldar原文§IV与§V-B](https://arxiv.org/html/0804.3010v2)区分全列秩和秩亏。
[Projected GSURE §4—5](https://arxiv.org/html/1003.3985v1)采用
\(P=L^\top(LL^\top)^\dagger L\) 估计可观测子空间的误差。
[Ramani等，IEEE TIP2012，§III](https://pmc.ncbi.nlm.nih.gov/articles/PMC3411925/)
明确区分predicted/data域和projected/range域风险；计算还需要重建算子对数据的导数。

**对本项目的推论：** 存在 \(v\in\ker L\) 时，\(x\) 与 \(x+v\) 具有相同测量分布，
却可以对相同重建有不同的全图误差。因此，不附加先验/限制就不能仅凭y识别任意
重建的完整PSNR，更不能用观测残差替代缺失区域和高频细节质量。
SR和修补尤其需要报告可观测域与全图质量的区别。严格的秩亏和数值病态也不能混为一谈：
模糊算子可能满秩但病态，不应未经奇异谱检查便全部称秩亏。

GSURE是一种可用的观测域风险工具，不是本项目已经实现的全图风险保证。
当前任务仍须由未用GT离线评价PSNR/SSIM/LPIPS；在线不接触GT。

## 3. 真正的自适应步长需要测量数值误差

[Gotta Go Fast §3.1—3.2与Algorithm1](https://arxiv.org/html/2105.14080v1)
用同一Gaussian增量构成Euler/改进Euler嵌入对，按混合绝对/相对容差计算RMS误差，
误差不超1才接受；随后按安全因子与误差更新h。每次尝试两次score，拒绝尝试也有成本。
其r=.9为经验选择，原文没有把ODE阶数公式直接作为SDE通用定理；
附录稳定性分析的线性测试SDE不覆盖任意引导ZAPS。

**对新实验的要求：**

- 相邻随机轨迹的转角不是该嵌入误差，也不自动给出可接受步长。
- 不能直接将连续SDE的Euler嵌入对替换到离散skip-DDPM并称同一个算法；
  需要指定连续向量场或离散粗细配对、同噪声耦合、端点、ζ/D映射与引导剂量。
- 拒绝时的随机增量处理、截断到端点、预算耗尽的状态必须明确；
  不能用独立噪声粗细差当离散误差，或把预算耗尽叫容差达标。
- 容差基于当前量纲/漂移而定，8位颜色启发式不是PSNR或感知质量的保证。
- 原训练270调用不变、末轮30改20，未计传感器时总成本仅节省10/300=3.33%；
  嵌入探测可能抹平收益。比较必须计总NFE和walltime。

## 4. 收敛为两个可否定模块

候选A：当前条件得分几何→引导缩放，按JAPS兼容笔记明确q/score/位移单位，
同时检验去掉状态、纯时间、跨图错配后是否失去质量或稳健性。
候选B：实际耦合粗细误差→步长，使用同一跨度系数接口与硬预算，
检验同总NFE固定/时间网格是否更差。二者先分开，最后才测协同。
这里是新机制的准入条件，不是已冻结控制律或可运行GPU卡。
