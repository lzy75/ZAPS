# A50r2的状态到倍率传导：明确可解释部分

新增阅读后的修订。固定同一步的物理回投v、真实网络回投u=J_m^T v和原修正q，
定义c_vu=cos(v,u)、c_qu=cos(q,u)。在非零且数值可辨时，当前ALIGN规则等价于：

    gamma = K(t,s) * ||v||/||q|| * max(0, c_vu*c_qu)
    correction = gamma*q

该式来自两次欧氏投影的代数分解，不是新曲率定理。||v||含当前残差、真实算子、
已知观测噪声和当前扩散水平；c_vu描述当前网络Jacobian怎样改变物理回投方向，
c_qu描述原ZAPS方向与当前真实回投的兼容性。它们都是同状态向量的夹角，
不是相邻随机轨迹增量的余弦，也不是Hessian、后验不确定度或数值截断误差。

在此ALIGN式中，||u||相消；因此不能称“敏感度范数越大，gamma必然越大/越小”。
DIRECT保留||u||，PROX只使用v，三者全路径对照才回答Jacobian及对齐是否有操作价值。
当q乘正标量时，gamma反比变化、gamma*q不变；当步ζ幅度被替换，D造成的方向仍保留。
cos(v,u)和cos(q,u)的乘积保留符号，不能各自先截零或取绝对值改变已有规则。

这是一套“物理回投+当前响应几何”解释，能作为原双状态想法的有界重构候选；
原开题所说“整段轨迹曲率→步长”依旧需要独立误差契约与实验，不能通过改名补齐。
当前r2只修旧customcheckpoint兼容，数学动作和4872预算不变；无Torch/画质结果。
