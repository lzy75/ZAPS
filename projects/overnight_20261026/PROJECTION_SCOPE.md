# 当前投影控制律能证明什么

本节解释A50r2已有设计，不引入新机制或新科学臂。公式的投影思想来自
[JAPS v3](https://arxiv.org/html/2511.18471v3)，不能宣称投影本身原创。
已补读该文A.1—A.5、B.1—B.3，区分下面三层。

## 1. 文献中精确恒等式与近似的位置

给定标准Gaussian前向扩散和观测条件独立，似然score可精确写为条件/无条件后验均值之差；
这个恒等式不要求数据先验Gaussian。把条件均值换成线性观测下的Gaussian近端解，才引入
各向同性条件分布等近似。A50r2的r²=(1−abar)/sqrt(abar)是这种选定参数化，不是实测协方差。

理想MMSE denoiser的Jacobian与后验协方差成比例，故对称且PSD；有限训练的网络未必满足。
我们计算真实网络输入VJP，是计算所给网络的导数，不是自动获得真实后验协方差。
一个方向上的vᵀJv为负可揭示对称部分沿该方向的负二次型；非负不能认证整个Jacobian为PSD。
单个VJP的范数也不是全算子谱范数或邻域Lipschitz常数。

JAPS B.3使用多次JVP/VJP幂迭代估计谱量。有限迭代的最大奇异值估计一般不是严格上界，
而某点Jacobian范数也不是整个步长邻域的上界。因此不能把该估计直接当我们安全步长的定理。
这只是约束后续推论，未据此否定作者算法实验；本项目不新增昂贵谱扫描路线。

## 2. 已有A50控制律具有一个几何位移界

对可分辨且有限的q、u、v，K>0，定义

    alpha = (v^T u)/(u^T u)
    target = K*alpha*u
    gamma = max(0,(q^T target)/(q^T q))
    d = gamma*q

alpha*u是v到span(u)的正交投影；d是target到非负ray(q)的欧氏投影。
投影不增加范数，所以

    ||d|| <= ||target|| <= K*||v||
    0 <= gamma <= K*||v||/||q||.

也可写成

    gamma = K*||v||/||q|| * max(0,cos(v,u)*cos(q,u)).

由此可解释：倍率本身不需要固定上限2；q很小时倍率可大，但精确算术下实际位移仍受当前
物理参照K||v||约束。正标量缩放q会使gamma反向缩放，所以d抵消当步正ζ幅度。
这个界只适用于已解析的正常分支；NA/fallback仍按单独日志和准入解释，不能套用此界。
有限精度误差、v估计质量和原始q是否可分辨也都需要服务器门控。

## 3. 若进入全部优化轮，需要另立梯度契约

只看正常分支、固定当前x/D，q=ζ*q0且ζ>0时，d不依赖当前ζ的幅度。
如果完整地对该前向函数求导，其当步ζ幅度导数应抵消；
如果把gamma stop-gradient后仍更新ζ，得到的是另一个替代梯度，不能叫原控制函数的完整导数。
历史前缀、D方向、fallback和块内相对参数仍可能有影响，不据此说所有参数都失效。

当前A50r2只回放末轮且冻结原参数，不涉及这个训练梯度问题。
若以后介入全部10轮，需要明确删除/保留哪些参数、是否采用交替替代梯度、如何计费和比较，
另做相同预算验证；不能以减少若干末轮调用推断原联合优化仍成立。

## 4. 这个界没有证明什么

K||v||自身可以很大，v也有模型误差；位移界不是通用安全阈值。
几何最小二乘不保证真实物理损失下降，不保证PSNR、SSIM、LPIPS改善，
更不是随机过程收敛、后验准确性、轨迹曲率稳定或NFE节省定理。
若q偏离有用方向，投影还可能丢失目标成分；这正是需要FULL_ALIGN方向参照和TIME/SHUFFLE消融的原因。
