# A85：含噪 ΠGDM 基线与倍率模块四任务对照

目标：先建立可核查的含噪 ΠGDM 本地基线，再判断现有 A71 倍率是否可迁移。不加固定／错配倍率，不改策略系数，不为失败宿主调参。

## 来源、公式及与 A84 的区别

原文：[ΠGDM, ICLR 2023](https://jankautz.com/publications/PiGDM_ICLR23.pdf)，完整核对第4–5页与第14–16页；算法1第14页，方差近似第16页。公开代码 NVIDIA RED-diff 固定提交 `66482f23e242bb31166c3662002d0a6f9f065030`，原字节与清单不修改，复用其训练噪声日程。新采样循环是**论文含噪算法的独立本地实现**，不称官方代码原样复现或作者基准均值。

模型坐标均为 [-1,1]，观测模型为 y=Hx₀+n，n~N(0,σᵧ²I)，σᵧ=.05。累计信号系数 ᾱₜ，原始干净预测 mₜ=(xₜ−√(1−ᾱₜ)εθ)/√ᾱₜ，不作 clamp。

原文 VE 噪声 σₜ²=(1−ᾱₜ)/ᾱₜ，第16页采用 rₜ²=σₜ²/(1+σₜ²)=1−ᾱₜ。这是原文各向同性近似，并非真实后验方差。记 eₜ=y−Hmₜ：

vₜ=Hᵀ(HHᵀ+σᵧ²/rₜ² I)⁻¹eₜ，gₜ=J(mₜ)ᵀvₜ，qₜ=√ᾱₜ gₜ。

c₁=η√[(1−ᾱₜ/ᾱₛ)(1−ᾱₛ)/(1−ᾱₜ)]，c₂=√(1−ᾱₛ−c₁²)。

基线：xₛ=√ᾱₛmₜ+c₁ξ+c₂εθ+qₜ。系数严格按算法1，不额外乘 √ᾱₛ。

本文模块：dₜ=Hqₜ/√ᾱₜ，ωₜ=max(0,1−Mσᵧ²/||eₜ||²)，γₜ=ωₜ max(0,〈eₜ,dₜ〉)/||dₜ||²，仅将 qₜ 替换为 γₜqₜ。退化零范数沿用原函数的零动作约定。调用未改动的 `noise_signal_shrink.select`；dₜ仍是同时间恒等响应代理，不是下一次网络响应；全局正幅度可能被投影抵消。

A84 使用发布代码的无噪伪逆路径、伪逆初始化、50点 η=0、额外 √ᾱₛ 系数，Gaussian 为发布代码的5-tap/σ25实现。其约6 dB Gaussian 结果不作为迁移正证据。A85 改为含噪正则化、纯高斯初始化、100点 η=1，并声明下列独立物理算子。因此 A84→A85 **不是单变量修复收益实验**，不能将差异都归因于协方差。A85 内 BASE/SHRINK 唯一差异才是 γ。

## 预算、门控与计时

固定100个网络索引 990,980,…,0，最后到干净端点−1；η=1。均为独立100次前向+100次输入VJP，不经过 ZAPS300 或学习缓存，无优化器反向。每数据集2400前向+2400输入VJP；SHRINK每步额外1次Hq，共1200H。每次加载模型额外1前向+1输入VJP单列，不掩盖重启成本。原文任务专用 warm start / 类条件模型等不在此使用；该统一协议并非复刻原文任务指标。

先运行必需 CUDA 数值门控：多通道显式稠密H、真实伴随、正则化解与直接求解一致，FFT与空间周期卷积一致、DC保真；固定状态梯度符号；独立算法1转录对照；强制γ=1完全一致；随机数/预算一致；原 checkpoint 输入VJP回归。缺Torch/CUDA失败，不能skip。加载实际权重严格核对 SHA 和 state_dict，并做真实输入VJP、以实测峰值+1GiB准入。FFHQ启动空闲至少6GiB，ImageNet至少10GiB；不终止其他进程，不降低精度/分辨率。FFT没有CG迭代或容差调参。

完整100步 wall-clock 包含观测/算子状态读取、算子构造、初始化、采样、CPU同步、进度记录。模型加载/权重检查、探针、观测创建、指标与文件写出另列；不把循环时间称为冷启动全耗时。报告每图PSNR/SSIM/LPIPS、原始浮点PSNR/输出范围/越界率、测量MSE、输入VJP/H/伴随/FFT成本、显存峰值、配对检查和失败。原始输出/PT/PNG留服务器，轻量记录分支自动上传，不合入master。

## 可否定判据与分支

每数据集每任务独立：平均PSNR增益≥.1dB，至少2/3图提升，SSIM不降且LPIPS不升，所有配对门控通过，才标为正向开发候选。PSNR<10或SSIM<.1的基线逐图标为异常，不凭它宣称迁移成功；阈值只作离线异常标识，不参与采样或调参。三图不能认证作者基准或普遍可靠性。

- 正向：保留该单元迁移证据，再确定需要的新图/噪声边界；本轮不加控制臂。
- 混合／负向：原样报告全部指标，不以单指标取胜。下一阶段再分析噪声正则化是否已抑制了相同误差、方向/坐标/响应代理是否合适。
- 数值失败/NaN：停止该worker、保留完整成本/错误，不自动失败重跑、回退或换参数。资源不足仅在未开始运行前暂停，可原命令续接。
- 若基线仍异常：定位算子、系数或初始化问题；不改 γ 救基线，不将异常上的差值当正结论。
