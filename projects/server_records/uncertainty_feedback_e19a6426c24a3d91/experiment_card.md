## 状态与对照定义

沿用r=y−A(raw m)、原测量逆系统v、u=J_m(x)^T v；令

```text
c_t = cos(v_t,u_t)
alpha_t = ||v_t||/||u_t|| * c_t
T_t = K_t * ||v_t||/||u_t|| * c_t * u_t
```

STATE精确复用A52的FULL_ALIGN，即K alpha u，不改乘法顺序重造旧轨迹。
所有对照都在**各自当前状态**重算v/u、使用当前u方向和当前||v||/||u||，仅替换c：

| 臂 | c取值 | 保留的实时信息 |
| --- | --- | --- |
| STATE | 当前cos(v,u) | 当前方向、范数、夹角 |
| TIME_COS | 同任务其他4图的逐步中位数 | 当前方向、范数 |
| SHUFFLE_COS | 同任务循环下一图的整条c轨迹 | 当前方向、范数 |
| NORM_ONLY | 固定1 | 当前方向、范数，无角度衰减 |

这修复了过去整条alpha/gamma打乱混入尺度不匹配的问题。TIME_COS只是系数按时间选，
不是整个方法“无状态”；NORM_ONLY也不是充分调优的旧固定F。只检验角度信息增量。
该余弦属于同一时间状态的v与J^Tv几何兼容性，不是相邻随机增量余弦，也不是轨迹曲率。
向量范数受K||v||限制是代数检查，不保证画质或后验正确性。
