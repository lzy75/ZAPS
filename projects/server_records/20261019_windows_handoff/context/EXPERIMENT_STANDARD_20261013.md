## 1. 三条工作线必须分账

| 工作线 | 目的 | 允许结论 |
| --- | --- | --- |
| R / 原文复现 | 固定原文已公开设置，核查实现与基线 | 原文规格兼容性/实现偏差，不混入新调度 |
| I / 初始调度 | 固定一个明确版本的ZAPS，只改变网格 | 相对同实现、同预算的固定调度收益 |
| A / 状态调度 | 在选定初始网格上，加入状态与预算控制 | 相对该初始网格的状态收益；再对最强固定基线比较 |

FFHQ历史结果含legacy_bicubic映射，不是精确伴随认证。可以作为明确标记的
开发基座，但正式方法实验必须锁定合理算子约定；不能用错误伴随的高分
替代原文基线。ImageNet的调度探索与原文复现分别归档，不互相覆盖。

## 2. ImageNet当前“无调参/无状态”基线：还不能称完全一致

已完成同图00001.png、seed1001、30×10、lr=.001、ζ/D联合学习、
DDPM fixed-small、eta=1、paper15/10/5、last_opt的参考结果：

| 任务 | 当前未调参参考 PSNR | 当前SSIM | 当前LPIPS | 原文均值 PSNR/SSIM/LPIPS |
| --- | ---: | ---: | ---: | --- |
| Gaussian Deblur | 19.5987 | .3168 | .6505 | 22.45/.682/.225 |
| 4× SR（exact transpose） | 19.9209 | .4798 | .5472 | 23.82/.718/.186 |

该表不是同样本的论文均值差值。Uniform的21.5069/20.0485属于另一个

**当前不存在已认证“与作者完整实现完全一致”的ImageNet基线。**

## 3. 初始调度：论文候选与优先级

目标不是承诺一个通用最优，而是在**当前模型、求解器、任务与预算**上，
筛选Pareto合适的初始网格。先只换网格，保持DDPM、方差、ζ/D、loss和
输出约定不变；换求解器的方案另立实验，不混入网格收益。

| 文献 / 候选 | 可借鉴内容 | 当前DDPM/ZAPS使用边界 | 优先级 |
| --- | --- | --- | --- |
| [EDM，Karras等2022](https://arxiv.org/abs/2206.00364)，[官方网格代码](https://github.com/NVlabs/edm/blob/main/generate.py) | sigma^(1/rho)均匀；rho家族 | 仅迁移网格，并非整个EDM/Heun；端点用本模型sigma范围 | 保留rho3/5，rho7复用旧结果 |
| [AYS，Sabour等ICML2024](https://arxiv.org/abs/2404.14507)，[项目页](https://research.nvidia.com/labs/toronto-ai/AlignYourSteps/) | solver/model/data相关的调度优化；Gaussian理想化arctan解析网格 | 不复制SD/SDXL时间点；解析网格只标AYS-inspired，不能称自然图像最优 | 新增优先候选 |
| [GITS，Chen等ICML2024](https://arxiv.org/abs/2405.11326)，[官方实现](https://github.com/zju-pi/diff-sampler/tree/main/gits-main) | 几何轨迹代价＋动态规划取点 | 原工作是ODE；其网格转入DDPM是待验证迁移，离线轨迹成本计入 | 第二批备选 |
| [DPM-Solver，Lu等NeurIPS2022官方实现](https://github.com/LuChengTHU/dpm-solver) | uniform-logSNR；误差容差驱动自适应ODE | logSNR可作网格对照；adaptive solver不是现有DDPM的直接替换 | 控制机制参考 |
| [Gotta Go Fast，Jolicoeur-Martineau等2021](https://arxiv.org/abs/2105.14080) | 自适应SDE步长、局部误差与拒绝控制 | 随机求解器需专门设计；每次额外score/拒绝尝试都计NFE | 自动步数设计参考 |

AYS给出的“最优”有明确假设；无条件生成优点不保证逆问题更好。GITS
ODE曲率理论也不能直接套到含噪DDPM。现阶段不把FID/生成效果当成
重建PSNR/LPIPS的替代指标，更不在10张图上用FID筛选。

### 3.1 坐标、总范围与步数范围

区分三件事：训练时间范围t，单跳跨度h，每轮模型调用数S。

```text
t ∈ {0,...,999}                   # 读取实际checkpoint的alpha_bar，不重设beta
sigma_eff(t) = sqrt((1-alpha_bar(t))/alpha_bar(t))
u(t) = (log sigma_max - log sigma_eff(t)) / (log sigma_max - log sigma_min)
u_start=0, u_end=1
```

这里sigma_eff是VP归一化噪声/信号比，**不是measurement noise sigma_y**。
先保持完整999→0覆盖，不通过降低起始噪声或删尾段“提升”分数。t=0
对应模型最后一次评估，后续净化端点不作log(0)。所有连续网格投影为
严格递减互异整数，保持端点；记录投影误差、重复点修正和最终真实S。

初始工作范围：S=20/30/60；30是锚点。10/15仅在后期低预算压力测试，
因现有ImageNet探索质量差，不作为最优初始化主搜索区。
20≤S≤60是本项目的起始工程范围，不是文献证明的通用最佳范围。

低成本先在S=30筛初始调度；候选胜出后再检验S=20/60。不要一次展开
“所有网格×所有rho×所有S×所有lr×所有任务”。EDM候选公式：

```text
sigma_j = [sigma_max^(1/rho) + j/(S-1)*(sigma_min^(1/rho)-sigma_max^(1/rho))]^rho
```

AYS-inspired解析候选：a_j在arctan(sigma_min/c)到arctan(sigma_max/c)
均匀，sigma_j=c*tan(a_j)，c在独立校准集上固定；不是完整AYS优化。
不同时展开多个c，优先从校准图像/模型域方差给出一个明确c，再验证。

### 3.2 高效筛选：缓存＋逐级淘汰，不用最终图调参

1. **0 NFE准入**：检查checkpoint/solver兼容、端点、取整、去重、网格
   指纹；匹配旧run的完整协议才复用，不按schedule名字复用。
2. **3图校准，S30×10**：至少保留paper和最强固定参照uniform；加入
   Karras rho3及一个新增AYS-inspired候选。rho5/7、logSNR等优先使用
   匹配旧记录，只有新增假设才重跑。单图只用于代码/机制检查，不选最终最佳。
3. **Pareto淘汰**：同预算下PSNR/SSIM越大越好、LPIPS越小越好；稳定
   被另一个候选支配则淘汰。保留最多2个候选及最强固定参照，不把
   物理loss单调下降当作画质改善，也不将多个单位直接相加做任意总分。
4. **独立10图确认**：既往0–9已参与探索，不能再称独立验证；固定另一
   组ID（例如10–19，先核实文件存在）且不逐图调参。使用同一seed表。
   若两候选差在重复误差内，选较简单的；小样本均值/胜率不是全球最优证明。
5. **稳定性**：在3张固定诊断图上补第二seed检验排序，避免每个候选全量
   重复。只有明显排序不稳才扩大种子，不无限追加直到显著。
6. **范围确认**：最终候选与最强参照比较20×15、30×10、60×5，均300NFE。
   这是步数—优化轮数预算分配实验，不能把差异全归因于S；必要时另做
   同10轮质量—成本曲线（200/300/600 NFE），分开报告。

最多5个候选×3图×300=4500方法NFE，缓存可减少；独立确认最多3方法
×10图×300=9000。新AYS/GITS离线训练/轨迹采集成本单列并报告摊销，
不能写成免费预处理。此处是预算上限，不是已启动任务。

## 4. 在初始调度上做状态微调：固定S先行，自动S后置

### 4.1 固定S的指标改造（提案，尚未验证）

已有参考曲线按“反向步位置k”对齐。动态S时必须改为按u噪声坐标
插值的reference(u)，否则不同实际噪声会被误当作状态变化。
先在固定S30做这个单因素门控，再增加指标或自由S。

令z_k为clean/Tweedie估计，观测噪声协方差Sigma已知时：

```text
r_k = sqrt(||Sigma^(-1/2)(y-H(z_k))||² / m)
u_k = u(t_k)
l_k = log(max(r_k,eps) / max(r_ref(u_k),eps))
E_r = tanh((l_k - EMA_previous) / s_r)
v_k = (z_k-z_(k-1)) / max(u_k-u_(k-1),eps)
c_k = cosine(v_k, v_(k-1))
E_c = tanh((c_ref(u_k)-c_k) / s_c)
```

使用clean估计而不是含噪x的更新；非均匀跨度归一化后再看速度/曲率。
余弦是角度曲率代理，不是Hessian，也不是严格局部截断误差。
可以补 `||v_k-v_(k-1)||/(||v_k||+||v_(k-1)||+eps)` 作为诊断，先不
增加第三个可调权重。高频/multiscale余弦沿用独立候选，不与其他改动
同轮混做。EMA按Δu而非固定步号调整，减少可变网格的采样密度偏差。

保留已探索的物理主导veto作为首个对照，不同时推翻所有映射：

```text
q_k = 1 - gamma*max(0, -sign(E_r)*E_c)
h_k = h_base(u_k) * clip(1-lambda*w(u_k)*E_r*q_k, h_factor_min, h_factor_max)
```

w(u)表示噪声阶段的响应可信度，先固定w=1验证坐标改造，再只引入一个
预先规定的低噪声渐增函数；不能按GT选择分段。一个备选是分开处理
残差超标与曲率偏大的正向“困难度”，密度乘exp(lambda*(.7*R+.3*C))；
权重.7/.3是开发起点，不是已验证最优。它与veto方案单独对照，不同时
扫描权重、lambda、阶段边界、stop阈值。

### 4.2 自动步数：上下限＋总NFE约束，不只是改循环次数

首版自动策略每轮S_min=20、S_max=60，锚点S0=30，优化轮数仍10。
若只约束S≤60，实际总NFE可到600，不能与固定300声称等预算。
因此设置全程B_total≤300，每轮启动时：

```text
b_epoch_max = min(60, B_remaining - 20*(epochs_remaining-1))
```

首轮参考曲线30次计入300；ζ/D仍联合学习。每个模型调用、拒绝尝试、
额外误差估计、净化/最终采样都计入方法NFE。首版不加拒绝重算，
先做只用已有状态决定下一跨度的预算控制；若引入嵌入式求解误差估计，
必须另立求解器实验卡，不能冒称零成本修改原DDPM。

重要工程前置：

- ζ/D定义在固定noise anchor上，以u(t)索引/插值，不能按可变k取“第k组”
  或在每轮变S时重建Adam参数。固定原网格的anchor命中应保留原值；
  插值本身先做固定S消融，别将插值收益/损失归因于自动S。
- 状态高难度缩小跨度，用更多调用；低难度放大跨度，减少调用。
  每一步限制剩余端点距离、最大允许跳跃及最少剩余调用，保证互异、
  到达t=0、终止且不超预算。不能一到上限就无条件做超大末跳掩盖失败。
- 若端点可达、S≥20、低噪声区、残差接近经校准的噪声容许带、clean
  估计相对变化小且余弦/曲率稳定（连续窗口，例如3个有效状态），才
  允许提前分配终止；最终t=0模型调用必须计数。若只停在t>0返回x_t，
  与原输出语义不一致；terminal jump超限则不算成功终止。
- 白化噪声的单位残差只作discrepancy量级参考，估计量依赖同一y且会
  拟合噪声，不能机械要求r=1；阈值在校准集固定，不在测试图上调。
  不能单凭残差小宣称视觉重建成功或逼残差为0。
- 终止状态区分 `criterion_met`、`budget_exhausted`、`invalid_trajectory`。
  有限终止可工程保证，**有限步正确收敛/画质提高不能预先保证**。

### 4.3 自动S的公平性与随机过程

固定预算先证明能改善质量；自动预算再检验“质量非劣同时平均NFE减少”。
报告total NFE的均值/分位数/上限、S逐轮分布、停止理由、最终噪声
位置及末跳大小，画质量—成本Pareto。可用+.1dB或节省10%NFE作
预注册工作目标，但它们不是文献定律；容许SSIM/LPIPS变化按重复实验
量级在运行前固定。不能事后挑最有利指标定义成功。

可变网格下共享同seed/步位置正态数属于common-random-number配对，
不是同一物理时间Brownian路径。自动S不同，末端RNG状态理应不同；
不沿用“所有变体末端RNG相同”的固定S门控。若使用SDE拒绝/重分网格，
需明确Brownian增量耦合/桥接及边际分布正确性，不随意重抽噪声。

## 7. 发布与结论门槛

- 主指标PSNR、SSIM、LPIPS必须同时报告；对既定固定参照和自己的null
  分别比较，区分初始化收益与状态收益。
- 微小差值先对照重复噪声；用配对均值、标准差、胜率，必要时配对区间。
  对校准集调过的最优不能当独立统计显著性；最终独立集只评价一次。
- 开发阈值不是“复现成功”阈值：原文复现还需要配置证据/样本协议。
- 任何实现修改先独立脚本和一致性门控，再决定是否同步single/batch/
  FFHQ/ImageNet；噪声、lr、H^T等不跨模型盲目同步。
- 本文所有新公式、预算阈值和队列为本项目提案。论文参考不提供当前
  ZAPS逆问题的通用最优网格或有限步收敛保证。
