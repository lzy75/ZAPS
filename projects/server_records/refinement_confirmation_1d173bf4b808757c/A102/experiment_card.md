# A102：共享学习前缀的严格等效300 NFE比较

固定FFHQ `00000–00009`、四任务、模型坐标噪声0.05。每个案例只运行一次完全相同的前9轮ZAPS学习（270次前向、9次反向），保存 `zeta/D`、Adam状态、固定初始噪声和RNG；随后从该状态分别运行原ZAPS、闭式标量、闭式对角末轮（各30次前向、1次反向）。

因此每个方法的算法等效预算均为300 NFE/10反向；联合实验真实执行为每案例360 NFE/12反向，二者分别报告。该共享合法，因为三个控制器只在第10轮不同；它消除了独立GPU优化造成的1–4%学习状态漂移。

对角前向采用真实H伴随的闭式解；straight-through只维持最终一次反向，而评价输出在该更新前已经确定。比较判据为每任务10图平均PSNR至少+0.1dB、至少7/10获胜、SSIM不降、LPIPS不升。
