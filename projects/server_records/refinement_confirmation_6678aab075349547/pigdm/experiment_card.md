## 固定条件与算法

FFHQ 00226/00443/00963，原seed，SR4/Gaussian/Motion/随机补洞，sigma_model=.05，256px/原精度。
逐项继承原checkpoint、观测y、H/边界/mask、原采样网格、DDPM噪声与输出语义；SHA和案例身份绑定到父plan。
DPS是原1000步单轨迹；ΠGDM是原100步单轨迹；均没有ZAPS式10轮学习或新的优化反向。
每步先计算原标量，再调用完全相同的A122对角模块；原q包含原方法的去噪器拉回/协方差方向，保持不变。
实际下一时刻干净预测采用原DPS clipped predictor / ΠGDM raw predictor；最终s=-1使用恒等。

```
h0 = P H C_s(x_s^0), r = P y - h0
omega = (1-M*sigma_y^2/||r||^2)_+
F(delta) = .5 ||P H C_s(x_s^0+delta)-h0-omega*r||^2
delta = delta0 + a*u + b*v
```

沿用A122的乘性增益链式法则和一次二维Gauss–Newton联合更新，真实F验收。
这是相同全系数增益方向的子空间更新，不改成完整对角变量的精确求解，不宣称矩阵全局最优。
原标量仍是父记录中的原算法，没有重新设计标量臂。GT只用于最终指标，绝不参与选候选或控制。
