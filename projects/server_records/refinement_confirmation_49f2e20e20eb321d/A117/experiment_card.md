# A117 固定网格下的方向与标量消融

目的：分别检验小波细化与像素域一步更新的关系、实时倍率相对固定时间表的收益、以及噪声收缩的贡献。父记录为完成的 A102，选定 FFHQ 00001、00004、00008 的高斯和运动去模糊，模型坐标噪声 0.05。按身份和哈希读取原观测与原运动核。

- 像素组和原对角组使用同一标量解、同一冻结目标和同一真实伴随。只改变更新坐标约束。像素轨迹逐步另算同状态对角修正，报告非零支撑、相对差、角度和代理值。像素末轮计时含同状态诊断的算子开销。
- 固定组使用同任务 A102 其余九图的逐时刻在线倍率中位数。只替换倍率的来源。供体不包括当例图像，不使用真值或终局得分。
- 关闭收缩组保留在线非负射线投影，只取收缩权重为 1。测量仍为原噪声 0.05。
- 每例共享九轮原 ZAPS 前缀，五臂为在线闭式标量、在线闭式对角、像素域一步、留一固定时间表、在线关闭噪声收缩。每臂等效 300 次去噪前向、10 次优化反向、0 输入 VJP/JVP。六例共同执行上限 2520 次前向及 84 次优化反向；同状态诊断额外物理算子和小波调用计入。
- 预期全支撑时同状态两种修正数值接近。若出现偏差，查支撑、数值与终局差异后再解释。两个标量对照逐任务保留所有配对方向与质量取舍。三图开发组仅用于机制消融，不做独立样本结论。
- 同一设备核对时间步、末轮 RNG 和前向/反向计数。独立目录保存计划、逐图质量、时间、轨迹、PNG 和服务器张量。实验失败不自动重试。
