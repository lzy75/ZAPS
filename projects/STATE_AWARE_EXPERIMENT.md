# 状态感知时间步实验（阶段 1）

## 固定基线

- 数据集 / 任务：FFHQ，4× 超分辨率，单图先验验证。
- 模型与算子：FFHQ 扩散模型；`legacy_bicubic` transpose；固定 skip variance。
- ZAPS：30 步、10 个 epoch、Adam `lr=0.01`、`zeta_init=0.1`、`D_init=0.2`。
- ζ 与 D 均按 ZAPS 原流程学习；状态调度器不额外缩放 ζ。
- 名义时间步：当前筛选出的 `uniform_30`。
- 公平性：所有变体共享观测 `y`，并通过相同 seed 共享 `x_T` 与按反向步位置生成的 DDPM 噪声；优化预算固定为 300 NFE。

## 代码门控

状态响应强度设为 0 时，自适应代码路径必须同时满足：

1. 访问的 30 个时间步与固定 `uniform_30` 完全一致，并包含最终 `t=0`；
2. ζ/D 的索引顺序与固定路径一致：`t=999` 使用末端参数，`t=0` 使用首端参数；
3. 单次 unroll 的前向输出与 loss 必须完全一致，且空自适应路径的 ζ/D
   梯度误差不得超过 fixed-vs-fixed 的 CUDA 重复误差量级；
4. 十次 Adam 更新会放大 CUDA 非确定性，因此最终门控以输出等价为准：
   重建相对误差不超过 `0.01`、PSNR 差不超过 `0.03 dB`；ζ/D 参数差异
   继续记录，但不再要求位级相同；
5. 两条路径均为 300 NFE。

单次探针实测 fixed-vs-fixed 梯度相对误差为 ζ `7.16e-6`、D `5.47e-6`，
空自适应相对 fixed 的误差仅为 ζ `1.50e-6`、D `1.87e-6`；这说明空
自适应没有引入额外梯度偏差。任一输出门控条件失败仍会停止后续实验。

## 状态指标

此前用绝对残差控制步长会在高噪声区过度密采，因此残差项改为相邻步骤的相对下降停滞度：

```text
relative_drop = (r_(k-1) - r_k) / r_(k-1)
E_r = clip(1 - relative_drop / q, 0, 1)
E_c = clip((1 - cos(Δx0_k, Δx0_(k-1))) / 2, 0, 1)
E   = w_r * E_r + w_c * E_c
```

其中 `q=0.05` 为首轮预设的目标相对降幅；首步或余弦尚不可计算时，相应指标取中性值 0.5。权重先比较：

- 残差单指标：`(w_r, w_c)=(1,0)`；
- 余弦单指标：`(0,1)`，仅作为对照；
- 残差主导组合：`(0.7,0.3)`、`(0.8,0.2)`、`(0.9,0.1)`。

状态代价大表示当前区域更难，下一跨度缩小；代价小则放大。首轮响应强度为 0.5，但跨度调制严格限制在 `[0.75, 1.25]`，并硬性保证 30 NFE 与最后访问 `t=0`。

## 判定顺序

1. 代码门控必须先通过；
2. 比较残差单指标与余弦单指标，判断信息来源；
3. 比较三个残差主导组合与固定基线；
4. 单图 PSNR 增益需要超过门控噪声量级（至少 `+0.05 dB`），且 SSIM/LPIPS
   没有明显恶化，才进入响应强度或目标降幅调参；
5. 单图筛选出候选后，再用 10 张图做配对验证，当前阶段不直接扩大样本规模。

## 阶段 2：残差平滑消融

第一轮单图结果中，余弦单指标相对空自适应下降约 `0.22 dB`；残差单指标
没有增益，三个组合也均未超过 `+0.05 dB` 的有效门限。同时访问时间步
呈现明显的大小步交替，说明瞬时相对残差下降可能受到 DDPM 随机波动污染。

下一轮不继续扫描权重，只增加一个变量：对相对残差下降使用 EMA：

```text
drop_ema(k) = decay * drop_ema(k-1) + (1-decay) * relative_drop(k)
```

首轮取 `decay=0.7`，比较 `adaptive_null`、原始 `0.7/0.3`、EMA
`0.7/0.3` 和 EMA residual-only。程序同时记录残差反弹率、`E_r` 在 0/1
的饱和率、步长调制触及上下界的比例和步长标准差。只有 EMA 版本相对
空自适应超过 `+0.05 dB` 且感知指标不恶化，才进入响应强度调节。

## 阶段 3：在线软归一化

EMA 实验没有减少抖动：组合分支的 `E_r=1` 饱和率由 23.3% 上升到
50%，调制触下界率达到 50%，步长标准差也由 9.30 增至 10.82。其 PSNR
相对空自适应仅约 `+0.049 dB`，同时 LPIPS 明显恶化，因此拒绝“直接对
残差降速做 EMA”的方案。

新的单变量假设是：主要问题来自固定 `5%` 目标和 `[0,1]` 硬裁剪，而非
缺少时间平滑。使用近期相对残差降速的在线均值 `m_k` 与绝对偏差尺度
`s_k` 做软自归一化：

```text
z_k = (relative_drop_k - m_k) / max(s_k, 0.01)
E_r = 0.5 - 0.25 * tanh(z_k)
```

由此 `E_r` 平滑限制在 `(0.25,0.75)`，不再发生 0/1 硬饱和；`m_k` 和
`s_k` 均以 0.7 衰减在线更新。下一轮仅比较 raw `0.7/0.3`、soft
`0.7/0.3` 与 soft residual-only，其他设置不变。

运行脚本：`projects/utils/diag_ffhq_state_schedule.py`。每次运行自动生成 `run.json`、`summary.csv`、`indicator_trace.csv` 和各变体重建图。

## 阶段 4：状态感知引导权重

在线软归一化解决了 `E_r` 的 0/1 饱和和频繁触边，但单图结果仍未超过
固定 uniform-30：soft combined 相对固定约 `-0.05 dB`，soft
residual-only 约 `-0.01 dB`。因此当前证据拒绝“仅靠状态重排 30 个时间步”
这一分支，不再继续扫描调度响应强度。

下一步固定 uniform-30，保持 ζ 和 D 按 ZAPS 原流程共同学习，只把状态作为
当前可学习 ζ 的小幅乘法因子：

```text
g_k = clip(1 + 0.20 * (E_r - 0.5) - 0.05 * (E_c - 0.5), 0.90, 1.10)
zeta_eff(k) = zeta_learned(k) * g_k
```

残差停滞时增强物理引导，轨迹余弦不稳定时轻微抑制；残差增益是余弦增益的
4 倍，符合“残差为主、余弦为辅”的设计。状态因子由 detached 标量构造，
不会截断 ζ/D 的梯度，也不冻结任何 ZAPS 参数。

`--variant-set weight` 比较四个实验臂：

- `soft_schedule_only`：只改变时间步，作为本阶段内部对照；
- `weight_residual_only`：固定 uniform-30，只调制 ζ，不用余弦；
- `weight_residual_cos`：固定 uniform-30，残差主导并加入弱余弦抑制；
- `soft_schedule_and_weight`：同时调整时间步和 ζ，用于检查二者交互。

两个 weight-only 变体访问的时间步必须与 uniform-30 完全一致。只有相对
`adaptive_null` 超过 `+0.05 dB` 且 LPIPS 不恶化的分支，才进入 10 图配对
验证；否则应认定当前两类状态指标不足以改善 FFHQ 超分基线。

## 阶段 5：排除 ζ 学习的补偿效应

阶段 4 中状态因子实际产生了约 `0.03–0.04` 的标准差且未触及边界，但
weight-only 与联合分支都没有 PSNR 增益。最后一个必要诊断是排除可学习 ζ
在十轮优化中吸收或反向补偿乘法因子。

`--variant-set posthoc` 先完成固定 uniform-30 优化，然后复制同一份已学习
ζ/D，在不再执行优化器更新的条件下做三次成对推理：identity、residual-only
和 residual+cosine。三者共享同一 `x_T` 和全部 DDPM 随机数，且都固定
uniform-30，因此只剩状态权重一个变量。结果必须相对 `posthoc_identity`
提升超过 `0.05 dB` 且 LPIPS 不恶化，才能说明状态信号有效而此前被 ζ 学习
补偿；若仍无提升，则结束这套状态到 ζ 的映射，不继续扩大增益或样本量。

## 阶段 6：围绕多种初始调度的参考曲线微调

前几轮实验说明，直接使用绝对物理残差或把残差与余弦线性相加，会混入
扩散时间位置本身造成的尺度变化；同时，余弦信号独立决定步长方向时容易
覆盖更可靠的物理一致性信号。因此本阶段保留两个指标，但重新分工：

- 第 1 个优化 epoch 严格沿初始调度运行，记录该调度的残差与 x0 轨迹余弦参考曲线；
- 后续 epoch 在相同采样位置比较当前残差与参考残差的对数比，并进行在线去趋势；
- 物理残差信号唯一决定下一时间跨度应缩小还是放大；
- x0 轨迹余弦只作为置信度门控，最多增强或减弱物理响应，不能翻转其方向；
- 总预算仍为 30 步 × 10 epoch = 300 NFE，且 ζ 与 D 均保持可学习。

具体组合不是再次直接相加，而是：

```text
e_r = tanh((log(r_k / r_ref,k) - EMA) / s_r)
e_c = tanh((c_ref,k - c_k) / s_c)
q   = clip(1 + gamma * sign(e_r) * e_c, 1-gamma, 1+gamma)
e   = e_r * q
h_k = h_base,k * (1 - lambda * e)
```

其中 `e_r` 的符号决定密采或疏采，`e_c` 只改变响应幅度；因此即使两个
指标意见相反，余弦也不能把物理一致性给出的方向翻转。

单图筛选同时覆盖 `paper_15_10_5`、`uniform_30` 与 `karras_rho_5` 三种初始
调度。每一种都设置 `null` 与 `refined` 严格配对，不能跨初始调度比较增量。
运行：

```bash
python -u utils/diag_ffhq_profile_schedule.py \
  --image /home/lzy/FFHQ/00000/00000/00000.png \
  --device cuda \
  --seed 1000
```

单图进入批量验证的门槛为：同一初始调度下 refined 相对 null 的 PSNR 提升
大于 0.05 dB，且 LPIPS 不恶化。通过后只对最佳候选运行 10 张图，避免继续
做无方向的全量参数扫描。
