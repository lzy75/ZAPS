## 2. 信息预测：四任务均未显示增量

OLD=旧R/物理近似/历史余弦等；P=真实下一步的物理响应；
I=不同倍率产生的clean响应方向、有限弯曲及幅度；PI=P+I。
STAGE=相同训练折每(step,gamma)的平均最终质量增益；不是A40的STATE倍率中位数表。
同任务整图留出只用同任务其他5图的标签；跨任务留出同时排除目标任务及当前图在其他任务的记录。
均使用固定ridge1，不在留出结果上改模型/阈值。

| 任务 | 同任务 STAGE PSNR MAE | 同任务 PI PSNR MAE | PI误差增加 | 跨任务 PI误差相对STAGE增加 |
| --- | ---: | ---: | ---: | ---: |
| SR | .03260 | .04545 | 39.4% | 42.3% |
| Gaussian | .06390 | .10768 | 68.5% | 6.8% |
| 补洞 | .03992 | .05580 | 39.8% | 26.4% |
| 运动 | .18830 | .33279 | 76.7% | 6.7% |

LPIPS预测相对STAGE也全部未通过保护。原门槛要求PSNR MAE下降10%，这里实际是增加，
所以不能仅通过放宽原阈值改称成功。P单独在同任务的PSNR预测也均差于STAGE。

结论边界：当前特征+固定预测器+六图设计没有建立增量，**不等于证明所有状态信息都无用**。
PI有9个数值特征及缺失指示，训练折只有5个不同图像内容；泛化误差/映射不合适也是可能原因。
本轮没有识别出它们各自的因果贡献，不能确定归咎于指标或ridge本身，不因此恢复无限调参。

## 3. 单脉冲确有四任务收益，但不能归为状态反馈

固定 k24/t319、gamma2 的最终均值相对C：

| 任务 | PSNR dB | SSIM | LPIPS | 本动作库逐图PSNR oracle额外空间 |
| --- | ---: | ---: | ---: | ---: |
| SR | +.03978 | +.00136 | −.00050 | 0 |
| Gaussian | +.16328 | +.00480 | −.00189 | 0 |
| 补洞 | +.10556 | +.00361 | −.00182 | 0 |
| 运动 | +.08835 | +.00298 | −.00198 | 0 |

所有均值方向良好；SR增益小于预设+.05工程线，仍可以如实报告小幅正向。
在当前五个倍率和这六图上，后段gamma2已无可见逐图PSNR择优空间；
不能要求状态选择在同一动作库中再凭空超过它。不是所有时间/所有gamma的全局结论。

其他有用的机制差异：SR在t641固定gamma2有+.33373dB/LPIPS−.00517；
补洞同点gamma2有+.22130dB/LPIPS−.00618；运动t872反而是gamma.5，
有+.26703dB/LPIPS−.00237。这显示任务/阶段不同，动作方向可不同。
不过这些位置和倍率由当前结果事后比较得出，不是状态自动选出的已确认规则。

运动t641的PSNR最佳固定gamma1.5只有+.06413dB，同时SSIM−.00435、LPIPS+.01001，
两项保护均失败，不能收入“综合画质正向”的方法结果。
该点PSNR-only oracle额外空间约.10931dB，不保证这些空间能满足画质保护或被状态获取。

## 4. 跨任务两处候选必须单列，不夸大也不抹掉

LEAVE_TASK_AND_IMAGE_OUT在t641：SR的PI−STAGE +.08182dB、
补洞+.05938dB，两处原动作候选门槛通过。它们说明当前映射有局部跨任务适配可能。
但尚缺所贴摘要中的：PI实际相对C、每图gamma、相对同任务最佳固定gamma2的差值。
若PI六图都选2且恰好恢复统一有效动作，允许称“任务规则迁移/适配”，不能称逐图自适应额外收益。
若有真实的逐图风险规避，需核验具体图像、画质与同任务强规则的差值。
同任务t641，SR/补洞的PI与STAGE收益恰好相同，也与统一动作解释相容，但不是完整机制证明。
