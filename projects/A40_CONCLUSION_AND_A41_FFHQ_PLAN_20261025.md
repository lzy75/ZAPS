C 是 A40 精确伴随、unit-domain、lr=.01 的本地 ZAPS 参考，非作者实现认证。
SR 的 C PSNR20.0086，双三次参照24.7528，STATE21.1689，提示基线失真指标仍弱；
C 的 LPIPS 更好，不能仅据 PSNR 断言代码错误，但也不能只报较弱 C 上的增长。
完整逐图、算子/配置核验与更强参考仍是正式论文方法结论的前提。

现有 STATE 主要是物理响应反馈，旧轨迹余弦未在线决定倍率。
它的倍率与同任务时间模板非常接近；旧 R/P/I/PI/PIG 未显示稳定的终局画质增量。
因此：物理缩放有条件价值；现有双状态控制、跨任务综合画质收益仍未建立。
不能将这个结论扩展为一切状态指标都不可能，也不再扫描旧指标权重。

## 需要改进的是测量对象

旧物理近似：由当前 clean+q/sqrt(alpha) 估计测量变化，没有实际经过下一次 UNet。
旧内在指标：随机轨迹相邻 clean 增量余弦；同时混入时间变化、噪声、引导幅度。
“转向大”本身不决定应该放大还是缩小 gamma，也不保证最终图像变好。

A41 在同一当前 x_t、同一个下一时间 s、同一个噪声 xi 下定义

    x_s(gamma) = 原 posterior(x_t, clean_t, xi) + gamma*q_t
    z_s(gamma) = 实际下一 UNet 的 clean 估计

物理 P：有效观测上的 R、实际 z_s(gamma) 的相对 measurement loss 改变、
测量响应与 residual 的夹角/相对幅度。补洞只统计 mask=1，避免纯缺失区噪声稀释指标。
这修正 readout，不改变原 C 的观测或优化 loss。

内在 I：d-=z_s(1)-z_s(0)，d+=z_s(2)-z_s(1)，记录

    c_action = <d-,d+> / (||d-|| ||d+||)
    K_action = ||d+-d-|| / (||d+||+||d-||)

再用 gamma=.5/1/1.5 的半跨度检验尺度稳定性，并记录响应幅度。
直观上：P 测“这个动作有没有改善测量”，I 测“响应是否近似线性、是否敏感”。
二者通过 **留出预测的最终 PSNR/SSIM/LPIPS 收益与风险** 决定 gamma，
而不是规定 K 大就必须减小权重。R 低也不直接等于画质好。

这是动作方向上的有限响应几何，不称整条轨迹的 ODE 曲率或真实 Hessian。
本轮没有在线闭环：用离线单动作到最终输出的标签，先判断它是否值得成为控制指标。
真实响应/高阶信息的研究动机可参考
[TMPD](https://arxiv.org/abs/2310.06721) 和 [CA-DPS](https://arxiv.org/abs/2412.20045)。
它们研究 Tweedie 高阶信息/条件协方差；本轮有限动作指标不是这些论文的复现，
不能借用其理论保证、复杂度或性能结论。

## 一轮同时回答的问题

6 张 A40 FFHQ 图 × SR/Gaussian/补洞/运动，固定四阶段、五个倍率。
SR/Gaussian 的 C 和兼容单脉冲终局结果复用；新基线3600、新诊断4212，共7812 calls。
不改网格，不恢复正则路线，不跑 ImageNet。

1. 分位置显示所有倍率最终 PSNR/LPIPS，计算最佳固定动作与逐图 oracle 的距离。
   如果最佳固定动作已经适合所有图，不虚构逐图自适应需求。
2. 同任务整图留出比较 STAGE / OLD / P / PI；预测器、缺失处理、阈值运行前冻结。
3. 同时留出整个目标任务和目标图在其他任务的所有记录，检验跨任务迁移，防止内容泄漏。
4. 输出实际留出选择的终局收益、风险和每图动作，以及所有图固定 x2 的对照面板。

每个位置是独立的一次干预，不能把四位置收益相加。
五点探测额外收费，不能把科学臂300 NFE说成免费在线300 NFE。
原生最终输出与 IEEE 探测严格分开，保留所有未分辨或有害响应。

候选证据需同时包括：预测信息超过时间/P、最终 PSNR 正向、SSIM≥−.002和LPIPS≤+.005。
精确门槛见实验卡；本轮六图是开发/机制试验，正向后仍缺：新图及第二seed确认、
完整在线反馈、把传感器计入成本后的比较、去掉P/去掉I的控制消融。
因此当前可以支撑状态测量与失败边界的论文章节，尚不能支撑“已实现四任务双状态优越性”。
