## 1. 本轮改动是什么

C是原ZAPS轨迹。所有分支从相同C中间状态分叉，只有当前一步的加性引导q
改为γq，γ为.5/1.5/2；之后恢复C并沿相同噪声继续到最终图像。
t641与t319是两个分开的实验，**没有把两个脉冲放进同一条路径**。
历史前270调用、原ζ/D、全部时间点、精度策略、观测与29个采样噪声保持一致。
GT在全部候选输出保存后才进入评价，未参与实际状态或分支生成。

R是噪声归一化残差；P是R＋残差/引导响应对齐＋响应相对幅值；
I是clean轨迹速度的相邻余弦、速度差及速度幅值；PI联合两者；
PIG额外加入真实H的clean空间物理梯度方向，而非经验transpose方向。
STAGE_NOISE只看固定位置和已知测量噪声，使用其他图像的平均效果作预测。
整张图及其两档噪声同时留出；离线ridge1诊断不等于部署的反馈控制器。

sigma=.05平均PSNR+.23350，低于时间规则+.25015；

## 4. 零调用补充核查：动作中有多少个性化空间

每个位置/噪声格，枚举保持C/γ.5/γ1.5/γ2的4^6种逐图分配。
GT只用于有限库事后上界；平均保护线保持SSIM≥−.002、LPIPS≤+.005。
这是新增描述性审计，不修改A39主假设，也不是一个可运行的GT控制器。

| sigma | 位置 | 最佳统一动作 | 统一动作ΔPSNR | GT逐图选择额外余量 |
| --- | --- | --- | ---: | ---: |
| .05 | 641 | 保持C | 0 | +.03183 |
| .05 | 319 | γ2 | +.25015 | 0 |
| .10 | 641 | 保持C | 0 | +.02258 |
| .10 | 319 | γ2 | +.17387 | 0 |

t319在两档噪声下，六图的PSNR最优动作都为γ2，因此已测有限库中没有
超过统一动作的逐图PSNR选择空间。t641有异质性，但平均理想增益较小，
当前状态没有可靠识别它。不能由此推断其他倍率、时刻、组合路径也没有空间。

均值保护不等于每图保护。高噪声t319的00609_s1000采用γ2时，
ΔPSNR+.17076、loss−.01490，但SSIM−.00347、LPIPS+.00856。
严格逐图保护的GT上界会将它改为γ1.5，整体PSNR+.16096、LPIPS+.00012。
因此这里仍有风险折中的含义，不能简单说任何state都毫无作用。
全72个脉冲只有4个LPIPS退化>.005，其中仅1个同时降低物理loss；
本轮对“物理改善但感知变差”的风险样本也较稀少，不能认证通用风险分类能力。

## 5. 对开题非步长部分的阶段结论

| 子问题 | 结论 |
| --- | --- |
| 物理一致性和内部轨迹能否测量 | 可以，回放/被动观测门控通过 |
| 引导缩放能否影响终局重建 | 可以，而且有阶段差异 |
| 残差是否足以代表画质 | 不足，上述00609是实际反例 |
| 当前余弦/转向是否是可靠调权指标 | 在本轮条件和固定预测器下未获支持 |
| 当前物理＋内部联合是否有额外收益 | 未获支持，不进入PI新图在线确认 |
| 整个开题中的状态反馈创新是否已成立 | 尚未成立，不能拿固定脉冲收益替代 |
| 跨任务、跨数据集泛化 | 未验证；本轮不能回答 |
| 步长/采样位置/NFE节省/收敛 | 当前用户排除的范围；本轮也没有这些证据 |

I量描述的是含既往采样噪声的历史clean转向，g方向也沿随t变化的随机轨迹。
它们不是固定t的干预敏感度，也不直接给出γ应增减的符号和幅度。
因此“轨迹抖动⇒该步减弱引导”不能作为已证明的控制律。
小样本下加入更多相关特征可能损伤泛化，本轮未分离是指标问题还是估计器问题；
不把固定ridge诊断失败扩大为所有映射不可能。
