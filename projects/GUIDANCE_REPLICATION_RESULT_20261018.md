## 4. 余弦和敏感度分别测什么

q_k是算法实际施加的测量引导修正，不冒称经过真实UNet输入Jacobian的完整物理下降梯度。
n_k=q_k/||q_k||；已有相邻引导余弦c_k=<n_k,n_(k-1)>比较相邻两步q，
不是相邻clean图像余弦，也不是相邻clean增量余弦，更不是同一步priorGuideCos。
Omega3用最近三个方向累计弦长除以原log-sigma坐标跨度，O3描述路径折返；
它们包含状态、时间、D_i及随机历史的共同影响。

固定时间探针冻结t/ζ/D，重新预测x±ηq0处的UNet输出，η=.01/.02：

    S_dir = ||normalize(q_plus)-normalize(q_minus)|| / effective_span
    a = RMS(q0)
    kappa_dir = S_dir/a
    Phi = [L(F_t(x_plus))-L(F_t(x_minus))] / effective_span

effective_span是原脚本记录的实际浮点扰动沿q投影跨度，接近2η。
S_dir是当前修正跨度内的方向响应；kappa_dir是沿q方向按状态RMS位移归一化的有限尺度响应。
二者不是全方向Jacobian/Hessian范数，也不是完整随机采样步的误差估计。
Phi<0是中央差分下降性质，不自动证明所有正向扰动低于中心、完整η=1修正必然下降，
或最终重建的三项质量指标会改善。A2a回贴没有逐个plus_loss/center_loss值，后续按完整JSON核对。

## 6. 对状态感知体系的含义

现在可以把物理一致性、实际方向变化和局部方向敏感度分开表述：

- 物理残差r：当前估计对观测的解释程度，仍为过程主读数。
- qCos/Omega3/O3：过去几步实际引导方向的连续性、变化密度和折返，不等价于有害振荡。
- a与kappa_dir：实际修正幅度与沿该方向的局部敏感度；S_dir保留两者共同作用。
- u、实际Δu和clip：解释上述状态所需的噪声阶段、采样跨度及非线性上下文。

这是候选状态描述，不是已经验证的控制器。此次H1通过只解决测量是否跨样本可读，
尚未证明qCos/Omega3能够预测kappa_dir，或在残差、噪声阶段、裁剪与幅度之外提供增量信息。
更没有证明高读数区域增加步数、削弱ζ或改变调度可以改善最终重建。
