## 3. 指标与消融

记z_k为clipped clean估计，u为原log噪声归一化进度，r=y−H(z)，
q为原版学得ζ/D构造的加性引导，a=H(z+q/sqrt(alpha_bar))−H(z)。

| 代称 | 输入／含义 |
| --- | --- |
| STAGE_NOISE | 固定k、sigma的训练图像平均效果，强时间／噪声对照 |
| R | log(R)，R=RMS(r)/sigma_y，单独检验残差 |
| P | log(R)、cos(r,a)、log(RMS(a)/RMS(r))，物理状态＋当前引导响应 |
| I | clean相邻速度余弦、归一化速度差、相对clean幅值的速度，内部路径状态 |
| PI | P与I联合；开题双状态增量的主比较 |
| PIG | PI再加精确clean物理梯度的邻步余弦／转向强度、q与该梯度的对齐 |

v_k=(z_k−z_{k−1})/(u_k−u_{k−1})；I的转向幅度为
RMS(v_k−v_{k−1})/(RMS(v_k)+RMS(v_{k−1}))。
小于32 eps_fp32×max(1,RMS(z_k),RMS(z_{k−1}))的位移不造余弦，置缺失。
g_k=−∇_z ||H(z)−y||²/(2m sigma_y²)，只反传实际H，不反传denoiser，
不调用历史经验transpose；梯度方向转向=sqrt(2−2cos(g_k,g_{k−1}))/Δu。
q与g对齐只为方向代理，不声称q是该目标的精确latent梯度。

所有状态只用当前／过去的C帧，所有脉冲共享该状态。clean/gradient沿随机路径
的转向包含既往采样噪声，**不是固定时间敏感度、ODE曲率或Hessian**。

每张图的两种噪声同时留出，训练侧插补、按k/sigma中心化、标准化、固定ridge1。
ridge仅为离线信息诊断，不是恢复已关闭的引导正则或部署了训练控制器。
24个状态×3个动作，不把它们当72张独立图。主指标等权汇总动作、再等权图像。
报告每γ和每t/sigma响应面，不能只报最好的动作／子组。
离线单步策略模拟：只用留出预测的PSNR及质量保护线选保持1或倍率；
实际效果由保存的最终输出评价。四个独立t/sigma单次决策格，不是在线多步控制。
