# A108 三位置在线方向与完整重建

状态 planned，A 工作线。A107 已在高噪超分、补洞的六个案例通过等长度单步诊断。
A108 检验同三个位置接回各臂的真实采样后，增益是否保留到终局。

## 配置与控制

冻结 A107 的 A103 父计划、案例、观测与掩码。固定 FFHQ 00001/00004/00008，
超分 ×4、70% 随机补洞、观测 sigma=0.10、第 10/20/29 步。
所有方法共享九轮优化前缀、末轮起点与随机数流，随后各自演化。
第十轮评价已生成的输出，省去仅更新未再使用参数的反向优化，五臂一致。

| 臂 | 在线规则 | 方法 NFE / 输入 VJP |
| --- | --- | --- |
| ZAPS300 | 原 ZAPS 修正 | 300 / 0 |
| SCALAR300 | 原闭式标量 | 300 / 0 |
| PROXY_DIAG300 | 标量加 A107 代理正交方向 | 300 / 0 |
| TRUE_RAY303 | 标量加真实响应梯度在原射线上的分量 | 303 / 3 |
| TRUE_DIAG303 | 标量加 A107 真实响应正交方向 | 303 / 3 |

两种对角方向均限定原小波支撑并去掉射线分量。真实响应两臂的梯度、观测目标、
方向更新位置和计数规则相同。每次新增修正都取该臂、该状态标量修正长度的 10%，
各轨迹分岔后绝对长度可以不同。零方向不替换，仍保留真实响应臂规定的探针预算。
每次 VJP 对应一次去噪前向，计入 NFE。没有试探接受或 GT 选步。

## 门控和判定

实际新增上限 2556 前向、54 优化反向、36 输入 VJP、0 JVP。按案例核对末轮
时间序列、最终 RNG、掩码及实际调用。保存逐图质量和观测/缺失区误差、耗时。

主比较为 TRUE_DIAG303 vs TRUE_RAY303、TRUE_DIAG303 vs SCALAR300。要求每任务
平均 PSNR 至少 +0.10 dB、至少 2/3 胜、平均 SSIM 不降、LPIPS 不升且干净观测 MSE 降。
补洞还需缺失区 MSE 降且观测区不升。303 等预算比较须三图两臂都实际应用三个更新。
同报 TRUE_DIAG303 vs PROXY_DIAG300 及 SCALAR300 vs ZAPS300。
若单步优势未延续或两道比较出现取舍，保留完整结果并停止向 29 步扩展。
这一小组是固定同面板的终局机制验证。
