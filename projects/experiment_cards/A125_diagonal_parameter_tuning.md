# A125 A118闭式对角的时间对齐与参数适配

状态 planned。2026-11-22。沿用A124R1完成的A118十图、Gaussian/Motion、同一观测与算子、模型坐标sigma=.05、种子、FFHQ权重、输出和指标。既有A124限幅组未带来保真度优势。本轮使用原A118冻结目标，优化步长和迭代次数。

A118末轮30点覆盖0..999，A124仅反馈t<=299。本轮把A118原30个时刻映射到原采样网格，按升序依次取可用且更大的最近位置，并为后续目标保留足量位置。DPS可精确映射，PiGDM映射到0..990每10一步且保留30个互异位置。实际映射写plan。所有标量与对角使用相同30个位置，其他位置运行原方法。各模型保留原循环与时间间隔。

固定目标J=.5||B delta-omega r||²，从原标量delta0开始。每次计算小波支撑梯度g和精确线搜索eta=||g||²/||B W^T g||²，取delta<-delta-kappa eta W^T g。K为1/2、kappa为1/1.5，共四组。全局正交小波支撑和原噪声收缩保持A118设定。额外位移没有相对标量长度的约束。0<kappa<2保证精确二次模型的该步下降，实际代码核对每次与最终代理损失。各迭代冻结同一omega、残差与原q，无额外NN/JVP/VJP。

十图按ID排序的前三图00108/00175/00431为开发组，两任务共六例。每模型独立校准一组参数，两任务共用，不能逐图选择。优先选择两任务均平均PSNR>=+.1dB、>=2/3图胜、SSIM不降、LPIPS不升、完整时间相对新标量<=1.10的候选，随后最大化两任务中较小的PSNR增益，再平均增益，平手优先少迭代、小步长。若无候选通过，仍固定最好的折中项，明确qualified=false。选择文件绑定开发输出哈希，保存后才运行其余七图。

其余七图每图运行同时间点标量和固定对角。它们已出现在历史A124中，本轮作为参数冻结后的复验面板，不称全新独立样本。两任务各报告三个绝对质量均值、逐图PSNR胜率和完整时钟。复验通过门槛为每任务平均PSNR>=+.1dB、>=5/7胜、SSIM不降、LPIPS不升；同时报告时间是否<=1.10。失败与取舍均保留，不能把筛选最优开发分数当复验结果。

每模型新增58个完整重建，开发30个、复验28个。20个原基线结果复用。DPS每臂1000F/1000原输入VJP，PiGDM每臂100F/100原输入VJP；新增网络求导0。开发搜索成本全部计入actual_new_cost。物理算子/小波开销单列。完整时间含输入/算子/采样/控制/输出CPU同步，模型加载、指标与写盘另计。固定配对观测、初末RNG、原网格和NN计数必须通过，GPU门控使用真实db4对象、两类DPS接口和PiGDM。数值或接口失败保留原尝试，直接停止。
