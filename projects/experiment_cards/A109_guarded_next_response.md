# A109 同状态降损与最终重建验证

状态 planned，A 工作线。复用已完成 A108 的六个案例、A103 观测与掩码、原 FFHQ 权重和 30 点网格。超分 ×4 与 70% 随机补洞各三图，观测噪声 0.10。A108 的真实响应对角修正相对同预算射线只提高 0.0205 / 0.0639 dB。本轮检验原候选在同状态是否实际降损，以及择优后局部下降能否改善终局。

## 同状态保证

固定当前状态，令原 ZAPS 修正为 \(q\)，闭式标量修正为 \(\delta_S=\gamma q\)。正交小波变换 \(W\) 下，\(\delta_D=W^\top\operatorname{diag}(w)Wq\)。取所有 \(w_i=\gamma\) 即得到 \(\delta_S\)。同一个损失与可行域约束下，对角阵的最优值不高于标量最优值。

对于冻结的线性代理 \(J(\delta)=\frac12\|B\delta-\omega Pr\|^2\)，\(B=PH/\sqrt{\bar\alpha_t}\)，\(P\) 取实际观测坐标，\(U\) 为原修正的非零小波支撑的合成映射。从 \(\delta_S\) 出发，令 \(g=U^\top B^\top(B\delta_S-\omega Pr)\)。当 \(g\ne0\) 时，取 \(\eta=\|g\|^2/\|BUg\|^2\)，则 \(J(\delta_S-\eta Ug)=J(\delta_S)-\|g\|^4/(2\|BUg\|^2)\)。零梯度时保持标量点。该等式针对冻结的观测代理，终局指标需独立配对评价。用 `utils/diag_equal_length_next_response.py --audit-a106` 可直接复核 A106 已存的代理损失，新增 0 NFE。

## 在线对照

沿用 A108 的位置 10、20、29、相对长度 0.10、方向构造及冻结目标 \(b=PH(m_t)+\omega P(y-H(m_t))\)。三组共享一次 270F/9B 前缀和末轮随机数流。每处以本组当前标量更新后的状态 \(a\) 为基准，同一 \(b\) 和下一时刻 \(s\) 实测 \(F(z)=\frac12\|PH(m_s(z))-b\|^2\)。一趟前向带输入 VJP 得到 \(F(a)\) 和方向，另一趟实测有限候选 \(F(a+e)\)。只在候选下降超过 \(64\epsilon_{32}\max(F(a),F(a+e),10^{-30})\) 时推进候选，其余推进 \(a\)。记录未筛选候选的上升、下降、零更新及数值容差内的次数。非有限数值结束该运行并保留记录。

| 臂 | 末轮操作 | 方法 NFE / 输入 VJP |
| --- | --- | --- |
| SCALAR300 | 闭式标量 | 300 / 0 |
| GUARDED_RAY306 | 真实响应射线候选和标量点择优 | 306 / 3 |
| GUARDED_DIAG306 | 真实响应小波支撑内的正交候选和标量点择优 | 306 / 3 |

两种候选在各自状态均为本组标量修正长度的 10%。因轨迹分岔，绝对长度可以不同。即使候选为零或被拒绝，仍计入评估前向和 VJP。额外评估不消耗采样随机数，记录实际调用时刻和末轮 RNG。实际新增 2232F、54 优化反向、36 输入 VJP、0 JVP。三组均取第十轮已生成输出，末轮不做仅更新未再使用参数的优化反向。耗时为前缀加末轮的同步实测，图像真值只用于终局评价。

## 判定

同状态报告每任务各 9 个候选的实际降损次数、采用后是否有损失上升、平均相对降损。采用后损失不高于标量点由选择规则给出，未筛选候选和实际降损幅度用于判断方向是否有效。终局主比较为对角 306 对射线 306 及对角 306 对标量 300。沿用 A108 判定，平均 PSNR 至少 +0.10 dB、至少 2/3 PSNR 胜、SSIM 不降、LPIPS 不升且干净观测 MSE 降。补洞还要求缺失区 MSE 降、观测区 MSE 不升。若局部下降但终局未达标，保留对照和逐位置记录，维持三处干预的验证范围。
