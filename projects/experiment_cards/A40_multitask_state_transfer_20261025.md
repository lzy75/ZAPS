## 1. 可否定问题与历史依据

问题1：现有无GT物理响应反馈在不同任务中是否仍改善最终重建？
问题2：实时state是否超过冻结时间规则、超过目标任务内无标签校准的时间规则？
问题3：冻结R/P/I/PI/PIG对单步动作终局效果的信息是否可迁移？
三个问题分别下结论，不能用STATE-C正向替代STATE-TIME增量或双状态成立。

A36原始响应在FFHQ SR低噪声有收益，但TIME也有效；A39在两测量中心，
P/I/PI/PIG的最终风险增量失败，t319有限倍率库无逐图PSNR余量。
因此不在同任务继续加特征；本轮改变任务/数据域，保留原定义和动作。

父run为 `/data0/lzy/ZAPS-results/diag_frozen_response_transfer/A36_20261023`
及 `/data0/lzy/ZAPS-results/diag_common_state_risk/A39_20261025`。
A39必须12case completed/门控/SHA通过；A36时间表、模型身份和原网格冻结。
旧代价不当本轮新增，全部新调用分方法和诊断记录。

## 2. 实验矩阵与固定设置

FFHQ / ImageNet × 4×SR / Gaussian Deblur，共4个条件。
每数据集从可访问历史run中排除已用文件路径和图像SHA，固定旧选择算法种子20261023，
从ID32–999的可访问PNG池选6张新图。两个任务共享同批图，sampling seed1000；
共24case、**12个图像簇**，不是24张独立图。候选池、历史审计与选中SHA在运行前冻结。
无图像替换、GT挑图、任务内倍率/阈值/学习率搜索。

| 项目 | 预设 |
| --- | --- |
| 图像/模型域 | 256×256，模型[-1,1] |
| 物理域 | A(x)=H((x+1)/2)，观测sigma_y=.05，不clip y |
| SR | DPS Resizer下采样4，实际精确伴随，Jacobian adjoint=.5H^T |
| Gaussian | kernel61，sigma3，zero padding，对称核的精确伴随 |
| checkpoint | FFHQ沿A36已核验SHA；ImageNet沿原始manifest已核验SHA，先核实后运行 |
| grid | 全部复制A36原30点，999→0；固定DDPM skip variance、eta1 |
| 优化 | 10轮、原ζ/D联合、db4/level3、surrogate false、默认Adam、原clip/投影 |
| ζ初值/D初值 | SR=.1、blur=.2；D=.2 |
| lr | FFHQ=.01沿开发基座；ImageNet=.001沿已锁本地原始设置，非新调参 |
| 输出 | 第10轮更新前last_opt，前270完全共享，仅末30的引导改变 |
| 评价 | 历史uint8 PSNR/SSIM、alex LPIPS；最终float物理loss另列 |

Adam采用betas(.9,.999)、eps1e−8；优化loss为观测MSE mean，ζ/D联合梯度norm clip1，
ζ投影≥1e−6、D无符号约束。denoiser clean估计clamp[-1,1]，不增加hard clamp mask。
实际导入的guided_diffusion script_util/unet/nn/fp16_util来源路径与SHA由服务器解析冻结，
不假定它们位于某个本机不存在的目录。

**SR由历史legacy经验transpose改为精确伴随，故四组均新建匹配C**，
不把旧FFHQ SR数字移作本轮C。此为明确的本地参考，不声称作者实现完全一致。
FFHQ/ImageNet的模型、数据与既有基座学习率同时按各自身份固定，
结果是各域内配对效果，不用跨组绝对PSNR推断因果机制。

## 3. 对照与真正的反馈规则

- C：原版ZAPS加性引导q，无新反馈。
- STATE：每一步根据当前观测响应选γ，完整复用I_cont2规则；不是PI控制器。
  r=y−A(z)，v=q/sqrt(alpha_bar)，a=A(z+v)−A(z)，
  c=cos(r,a)，b=||a||/||r||，γ候选=clip(c/b,0,2)。
  对.5||r−γa||²的相对预测改善不足1%时回退γ1；零向量沿原规则回退。
  c、b是当前物理方向及响应尺度；R=RMS(r)/sigma只是状态读数。
- TIME_SOURCE：A36已冻结的FFHQ旧图时间表，全新任务不校准，不使用目标GT。
- TIME_TASK：其他5张目标任务图的STATE轨迹逐位置中位数；排除当前整张图。
  没有质量标签/GT拟合，但**属于目标任务无标签校准，不是零样本迁移**。
  五条外部STATE轨迹的数据取得成本必须披露，不称免费独立300-NFE部署。
- NAIVE：SR将观测双三次放大；blur直接使用观测图。0 UNet，用于弱C基线检查。
  不参与反馈或GT输出选择；若C弱于NAIVE，标明实用质量结论受限。

所有在线方法只依赖观测/当前状态/冻结时间表，不读取GT。
每图先生成并保存全部输出再评价；任务时间表只读其他图的gamma，忽略质量指标。
每条科学轨迹由原270＋该臂30组成，都是300；诊断回放单独分账。
内部轨迹余弦/转向未获A39支持，**本轮不将它们强行用于在线控制**。

## 4. 固定指标的迁移信息检验

同时观察C全轨迹的原R/P/I/PI/PIG，定义完全沿A39，不加新指标和权重。
在k19/t641与k24/t319的共同C状态，单次γ=.5/1.5/2后恢复C，获得最终质量差。
两个位置和各倍率是分开的路径，不将收益相加。

分别报告：

1. **冻结来源预测**：仅用A39的源图标签拟合原ridge1/插补/标准化/阶段中心，
   新任务标签只评价。新的精确算子也构成协议域差异，需明确披露。
2. **目标任务整图留出诊断**：配方仍ridge1不调参，检验信息在目标任务内是否存在。
   它使用其他目标图的GT标签，故只是离线诊断，不称零样本迁移或在线方法。
3. **动作空间**：4^6有限逐图GT选择上界，仅说明已有动作是否有个性化空间；
   绝不在实际方法中用GT选倍率或最终输出。

主信息候选仍最终LPIPS MAE相对时间与P各降≥10%、≥4/6图改善；
PSNR/SSIM/loss均保存，不能挑子组或换主指标。小样本规则为工程pilot，非显著性证明。
历史随机轨迹转向保留采样噪声，不改称真实曲率或固定时间局部敏感度。

## 5. 成本、资源与门控

每case：原C优化300；C被动回放30＋6条单脉冲后缀45＋STATE30=105诊断；
两个TIME各30=60诊断。总计24×(300+105+60)=**11160调用**，
其中7200方法、3960诊断。无额外最终采样/拒绝重抽或未计score。
H前向及H反传0 UNet但单独计时；采样时间含记录开销，不宣称端到端提速。
TIME_TASK取得其他图STATE轨迹有校准数据成本；C前270共享不会使它免费。

- 精确算子IEEE-only VJP/内积门控≤2e−5，0 UNet；生产恢复同一native precision。
- 真实C回放相对误差≤1e−6；实际调用序列、29噪声、ζ/D/tau、RNG及model无梯度门控。
- 两checkpoint预先SHA、所有worker/输入/输出签名；PRE和原输出独立保存。
- 服务器强制执行Torch真实算子/core数值检查；任何skip或门控失败不启动该实验。
- GPU≥10GiB空闲，尊重CUDA_VISIBLE_DEVICES；双卡并行，只有一张可用则串行。
- 第一阶段完成所有STATE后才生成排除当前图的TIME_TASK；第二阶段连续执行两个TIME。
- 失败保留attempt及调用，重跑入口复用completed；中断调用成本标下界。
- 不覆盖历史核心、默认配置、父结果或冻结卡片。

## 6. 判据和后续分支

每个条件分别报告STATE−C、TIME_SOURCE−C、TIME_TASK−C、STATE−两TIME。
STATE−C候选：PSNR均值≥.05dB、≥4/6图正向、平均SSIM≥−.002、LPIPS≤+.005。
STATE额外信息候选：同时对两个TIME PSNR≥.02dB、各≥4/6图正向、同保护线。
保护均值不替代逐图退化计数/极值。6图bootstrap区间只作未校正描述，不冒称置信结论。

| 结果 | 可以说什么 | 下一步 |
| --- | --- | --- |
| STATE-C正、STATE-TIME不正 | 响应改造能迁移；实时当前图状态必要性未成立 | 保留简单规则，停止state优越性宣称 |
| 仅某任务有STATE-TIME增量 | 条件性state候选 | 冻结该条件并做未用12图/第二seed确认 |
| 四组均有STATE-C及两TIME增量 | 小样本跨任务state候选，非全局泛化 | 独立扩大确认，不再调规则 |
| 指标目标LOIO有效、来源预测无效 | 信息可能存在，但映射迁移失败 | 另列校准，不能称零样本 |
| 只有P有效、I/PI无增量 | 物理状态有信息；开题双状态仍缺证据 | 如实缩小贡献，不重启余弦调参 |
| 动作无异质性、state无增量 | 当前动作/指标体系不支持个性化控制 | 负结论收口，不靠盲目扩倍率制造创新 |
| C明显弱于NAIVE | 当前本地基座实用性受限 | 分开处理基线问题，不将修复收益冒充state收益 |
| 门控失败 | 无算法结论 | 修具体接口，保留失败成本 |

本轮回答固定调度下的调权与信息迁移，仍不能证明步长分配、NFE节省、
正确收敛、全10轮反馈或硕士论文已达到学校要求。
