# A129：单次对角更新在后续采样中的传播

日期 2026-11-23，工作线 A，状态 planned。A128 在相同额外计算下观察到 ΠGDM 的对角更新降低下一次干净预测误差，终局绝对 PSNR 差小于 0.0005 dB。A129 检验收益在哪个后续状态衰减，以及由两条轨迹各自计算的物理修正是否参与抵消。

- 固定 FFHQ 图像 00108、Gaussian/Motion 去模糊和模型坐标噪声 .05。父记录是 A118、A126 ΠGDM 和 A128，均需完成。继承各自观测、算子、模型权重、seed 和时间网格。跨模型算子、网格和干预规则各自沿用历史记录，因此跨模型差异是机制线索。
- ΠGDM 精确重放 A128 八条干预轨迹，在 920 或 90 比较一次额外射线与一次全系数对角更新。锁定同一原生状态、原始物理方向和真实响应射线解，后续沿原 A126 射线策略。核对配对 RNG、网格、输入导数成本和 A128 终局原始 MSE。
- ZAPS 使用 A118 的前九轮共用学习前缀。以实测 log-SNR 在原网格中找两个最近位置。每个任务重放一次原闭式标量轨迹，再做两个分支，各在对应位置将标量替换为 A118 原闭式对角，其他位置沿标量策略。核对标量对 A118 存档的相对 L2 ≤ 1e-4、两分支的介入前状态和最终 RNG。
- 每对记录最多五次后续原生干净预测，靠近终点时记录实际存在的次数。记录全图与干净观测的配对 MSE、累计 log-SNR、无引导下一状态差、引导差及结果状态差，加引导前后比率与引导在无引导差方向上的带符号投影。终局同时记录 PSNR/SSIM/LPIPS。
- 当初始局部全图 MSE 下降至少损失一半，取第一次满足条件的已记录相邻转移，仅离线给两个无引导状态加上同一个标量分支的引导，各重新预测一次。检验误差是否恢复与量化原转移的引导影响。如果起初没有优势，或五步内没有达到衰减阈值，记录对应轨迹即可。真值只用于离线量化和挑选这个分析位置，所有采样轨迹已先完成。
- 上限 2968 NFE，包括 ΠGDM 8×279、ZAPS 两个 270F 前缀及六个 30F 末轮、最多 16 次影子前向。记录真实前向、VJP/JVP、优化器反向及重建或末轮计时。异常保留已完成的 JSON，不自动重跑。结果仅用于单图归因。
- 若去噪后差异仍在，原引导明显缩小状态差且共用引导恢复局部收益，优先查原物理引导抵消。若共用引导也无法恢复，优先查去噪采样。两种方法单次都衰减时再考虑连续窗口的累积证据。
