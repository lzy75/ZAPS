# A105R1 同会话控制器噪声消融

状态 planned。A105 首例跨会话回放相对 L2 为 1.7e-5，超过预设 1e-6，停止于
超分闭式标量真实噪声臂。A105R1 改用同会话对照，独立保存结果和失败记录。

沿用 A105 的六例、固定的 A103 观测噪声 0.10、检查点、算子、掩码和网格。
每例训练一次共同九轮前缀，所有末轮从同一参数、优化器状态、初始张量和 RNG
开始。依次运行两种方法的真实 0.10、各自的 0.10 重复、同会话 ZAPS300、
以及两种方法的固定 0.05。两个重复的相对 L2 均须不超过 1e-6，同时末轮
计数、网格和最终 RNG 一致，才允许跑固定臂。跨会话与 A103 的输出差异
单独记录。主比较为同方法、同会话的固定 0.05 减真实 0.10。

每个方法仍为 300 NFE、10 次优化反向、0 输入 VJP/JVP。六例新增预算
6×(270+7×30)=2880 NFE，96 次优化反向，包含两条重复末轮及本地 ZAPS 末轮。
报告同会话配对 PSNR、SSIM、LPIPS、修正置零次数、超分干净和带噪观测误差、
补洞分区 MSE。GT 仅在所有末轮及门控完成后用于评价。判定标准沿用 A105。
会话内复现失败保留具体误差并停止。小样本结果用于机制归因。
