# A54：实时范数响应增益是否优于时间/错配/常数增益

状态：planned，A线开发消融；不改A53及更早文件/判定。

## 依据、命名和可否定假设

A53完整10例：余弦衰减STATE没有实时角度增量；去掉衰减的NORM_ONLY在两任务5/5图同时改善
PSNR/SSIM/LPIPS。对C_IEEE平均PSNR约SR+8.092、IP+8.343dB。
结果提交5f3008e473598963f0ed1893a4ac5745a5546dff；摘要SHA
e5038b8f1ec746fd457c367c79289303349c344278035657183d7830cb7a9d35。
停止当前余弦衰减的系数扫描，保留负结论；不据此否定所有角度指标。

本轮STATE_GAIN明确指A53的NORM_ONLY，**不是A53带余弦的STATE**。
令u=J_m(x)^T v、g=||v||/||u||，位移T=K*g*u。
STATE_GAIN仍实时使用当前物理目标v和去噪器伴随响应u；固定c=1不等于固定引导倍率。
g是局部方向响应增益的倒数，不是后验协方差、全局Lipschitz常数或轨迹曲率。

假设：当前g比同任务时间模板或另一图的g更适合校准当前u。若未通过，不继续扫描本范数比的
阈值/上限追正值；保留几何归一化方法的质量候选，但不授予实时标量匹配创新。

## 唯一改动和公平性

4臂均保留各自当前u方向，均无余弦衰减，只改变g来源：

| 臂 | g来源 |
| --- | --- |
| STATE_GAIN（全部缓存复用） | 当前||v||/||u|| |
| TIME_GAIN | 同任务其他4图NORM_ONLY轨迹的逐步中位数 |
| SHUFFLE_GAIN | 同任务循环下一图的NORM_ONLY整条g轨迹 |
| CONST_GAIN | 同任务其他4图所有时间步g的中位数，整段不变 |

排除自身图像，只读响应日志，不用GT或最终画质拟合数值；所有系数运行前冻结。
CONST是匹配中位数，不是GT充分调优的最强固定参照。TIME只表示系数按时间，整个方法仍使用当前u。
外国/时间g可能使位移超过当前K||v||，这是被测干预；不能再用当前g去裁剪，否则重新引入反馈。
不加任意倍率上限、不放宽CG门槛；若非有限则保留已耗调用并停，不自动重跑或扩大预算。
