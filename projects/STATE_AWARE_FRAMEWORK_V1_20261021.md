# 从当前状态到采样动作：开题主线的重新设计

2026-10-21。状态：研究设计，未实现新控制器、未运行新GPU实验。
本次只整理证据与下一阶段的定义，不修改历史核心、实验脚本或结果。

## 1. 研究问题与已经排除的解释

目标是从当前重建状态决定下一步的跨度与物理引导，并在给定总调用预算内形成
图像自身的采样分布；允许在质量容差下进一步减少调用数。
固定时间点的修正只能作对照，不能用它的收益代替状态感知收益。

开题的两条主线保留：内在局部稳定性、外在物理一致性；需要重建的是二者的
操作性定义和动作映射，而不是继续细扫上一版R/Omega的混合权重。

已完成的A23–A27说明：

- 相邻方向余弦可测，但未证明能够决定有益步长或引导倍率。
- 所选双状态S在12张确认图上没有证明PSNR增益；相对固定F平均低.289453 dB。
- F相对C平均提高.267545 dB，属于固定引导改动的证据，不是状态感知证据。
- 确认S选择rho=0，实际没有移动采样位置；之前每原单元一点评估，也不是区域调用数重分配。
- 这些结论针对已测的有限参数族，不排除其他状态指标；也不支持直接放大旧权重再扫描。

详细证据见[A23–A27阶段结论](A23_A27_FINAL_STATE_FEASIBILITY_20261021.md)。

## 2. 一个体系，三个控制结果

链条为：当前状态 → 候选动作的响应/风险 → 预算内的下一步动作 → 更新状态。

| 需要完成的任务 | 控制变量 | 所需信息 | 成立的证据 |
| --- | --- | --- | --- |
| 选择步长、必要时改变步数 | 下一噪声位置s，或跨度h | 该跨度的局部响应与误差代理 | 同成本时比固定跨度更好，或同质量时总调用更少 |
| 分配整个过程的调用 | 随当前状态产生的多个h及剩余预算 | 当前难度、近期趋势、端点可达性 | 调用密度确实变化，优于阶段固定分配 |
| 每步缩放物理引导 | gamma，实际修正gamma*q | 增加修正的物理收益与局部风险 | 优于固定gamma/固定倍率曲线，且不是额外调用的收益 |

区域调用分配应由连续的在线选步产生，不另设“固定在哪个t插点”的核心规则。
在固定总调用下，困难区域用小步、更多评估，平稳区域用大步、更少评估。
自动步数是另一种评价模式：固定质量容差，报告不同图像实际消耗的全部调用。
这两种模式不能混报为同一个等预算实验。

## 3. 状态通道：物理缺陷和内在敏感度分开定义

### 3.1 当前可直接读出的状态

记z=D_t(x)为当前clean估计，q为当前ZAPS物理修正，H为物理前向算子。
这里q是现有近似预条件修正，不能未经核验就称精确似然梯度。

物理缺陷使用白化残差：

    r = Sigma_y^(-1/2) * (y-H(z))
    R = RMS(r)

R说明未拟合观测的程度，不说明继续增加引导一定改善画质。
R=1只是测量噪声尺度参照，不是必须达到的目标或停止条件。
无测量噪声时必须另定尺度，不能除以零。

内在历史读数保留，但降为待验证的预测特征：

    n_k = q_k / ||q_k||_2
    theta_k = acos(clip(<n_k,n_(k-1)>,-1,1))
    omega_k = theta_k / (u_k-u_(k-1))

u是由实际alpha_bar计算的归一化log-sigma进度，随去噪从0到1。
窗口长度按Delta_u固定，不按固定几个采样点定义；窗口只读当前及过去。
记录窗口内总转角/窗口长度，以及总转角减首尾夹角的非负值/窗口长度，
分别描述方向转动量和往返转动。小范数q不计算方向，记NA并触发已定义回退。
这些是历史方向变化率，包含时间变化和随机路径影响，不是已经测得的曲率。
不得因为窗口更平滑就宣称它更有效。

### 3.2 需要校准的局部敏感度

核心变化是测“当前场对实际候选位移有多敏感”，而非只看之前转了多少角度。
先在固定噪声t、同一个中心x作诊断；沿候选确定性位移的单位RMS方向v，
评估x±epsilon*v，使用两个尺度及中心重复。

    L_dir = ||n(x+epsilon*v,t)-n(x-epsilon*v,t)||_2 / (2*epsilon)
    L_mag = |log RMS(q_plus)-log RMS(q_minus)| / (2*epsilon)

方向n使用单位L2范数，v使用单位RMS；epsilon因此表示每像素RMS位移。
对候选位移delta_mu，可记录L_dir*RMS(delta_mu)和L_mag*RMS(delta_mu)，
分别作为方向改变和幅度改变的线性预测。这是有限尺度方向敏感度，不是全Hessian，
也没有包含改变t的影响；需要后述跨噪声候选响应验证。

只对高于中心重放误差、两个尺度一致的读数解释。IEEE/TF32、clamp、
仿射H的Jacobian、q范数下限沿用既有门控经验；不能重复把A13的精度发现当新结果。
若使用波列近似Jacobian作零UNet替代，须先和真实探针对照，不能默认正确。

这些探针初期属于离线诊断。将来在线使用时，其调用全部计入方法成本。

## 4. 从状态到动作：需要验证的定义

### 4.1 先把候选一步写准确

对当前t与候选s<t，定义现有跳步核的条件均值：

    mu(h,gamma) = DDPM_mean(x,z,t,s) + gamma*q_t
    h = u(s)-u(t)
    z_next(h,gamma) = D_s(mu(h,gamma))
    R_next(h,gamma) = RMS(Sigma_y^(-1/2)*(y-H(z_next)))

这是诊断用条件均值读数，不是最终随机采样结果。实际一步还要注入规定方差的噪声；
必须检验条件均值读数是否能预测随机一步及最终重建，不能直接等同。
读数依赖当前x、z、q、观测y和候选噪声位置，不依赖固定动作t、图像ID或GT。

同时测同一跨度的一步/两子步条件均值组成差异：

    E(h,gamma) = RMS((mu_fine-mu_coarse) / (atol+rtol*max(abs(mu_fine),abs(mu_coarse))))

fine/coarse必须采用冻结场端点一致、物理修正总作用量一致的组成契约。
不能把同一q在两个子步各加一次，再把增益说成更细步长的收益。
E目前只叫组成差异或误差代理；含神经场、随机采样和离散学得参数时，
尚无证据称其为严格局部截断误差、全程误差界或收敛保证。

因此两条主通道是：

- 物理通道：当前R，以及候选动作改变R的效果。
- 内在通道：候选位移下方向/幅度敏感度与组成差异，附带测量可靠性。

这里不是重新制造多个自由加权指标。先分别测可靠性和增量作用，
通过消融后才决定线上保留哪些量；历史余弦不能自动获得控制权。

### 4.2 引导缩放：按有效响应，不按“残差大就加倍”

固定当前h，比较少量预先冻结的gamma候选，观察R_next的改善和内在风险。
候选增大gamma仍有效、风险在可信范围内，才允许增强；若响应失真、超出局部
线性范围或损害clean结构，则限制倍率。倍率变化率也受限。

“损害clean结构”初期只能用相对未加修正候选的clean变化量作信任域代理，
不能把它称为无GT画质判定。此代理是否有用也要由终局实验验证。
不预设方向变化大必然减小gamma：它也可能只是当前步过大，应该先减h。

第一版可检验规则是：在内在风险/变化幅度约束内选物理缺陷较小的gamma；
重复误差内无差别时选改动较小者。它是待否定假设，不是已验证最优控制律。

### 4.3 步长和预算：按候选风险选择，分配自然产生

给定gamma，选择满足风险容差、跨度上下限和剩余预算约束的最大h。
局部风险较大时缩步；风险较小才扩步。每次更新后重新测当前状态。
候选若需多次UNet才能比较，不能把它们隐藏到诊断成本之外。

先在诊断中确认风险对跨度的排序是否成立；若不成立，不能套用固定幂次的
h更新公式，更不能从不稳定的读数推导自动步数。

严格预算版本须在每次查询前预留到达t=0所需最低调用，区分实际接受位置数
与全部UNet调用数。预算不足且容差未满足，记录budget_exhausted，不能报告criterion_met。
全程分配是这种因果决策的结果，不使用未来轨迹或事后最好时间点。

## 5. 在比较方法前必须解决的接口

1. 噪声坐标：从checkpoint真实alpha_bar确定，端点不变，严格递减整数投影，保存实际跨度。
2. 参数映射：ZAPS的zeta/D是离散每步学得的修正，不是已定义连续漂移。
   新位置的映射与细分时的修正总作用量必须单独冻结；原锚点应复现，冻结场应组成一致。
   原锚点复现是必要条件，但不能据此认证任意新位置插值正确。
3. 随机性：相同slot随机数不等于同Brownian路径。离线配对桥与线上自适应须分开；
   首版决策不读取未来将注入的随机数，避免按噪声挑步。条件均值控制也不自动保证SDE无偏。
4. 精度：测量精度改变若影响轨迹，两臂必须采用同一生产精度；不可将精度收益混入状态收益。
5. 成本：若一次接受步耗两次UNet，30次预算只能支付约15次这类接受步；
   探针、拒绝、最终净化和回退全部计入。反传/算子时间另报，NFE相同不等于耗时相同。
6. 先冻结原前270次只研究最后一轮，可降低开发成本；此时只能证明局部控制，
   不证明全十轮可变步数或节省总NFE。全流程验证后置。

## 6. 分阶段实验：先证明读数有意义，再证明控制有收益

这是新研究顺序，不是已启动的A28或现成服务器入口。运行前按实验卡模板冻结
具体缓存身份、状态位置、候选数、容差、调用总表和停止规则，避免边跑边改。

### I：当前状态是否能区分动作的效果

先复用六张旧开发图、每图两个seed的可回放状态，覆盖整个噪声进度；
不按GT或已有收益挑状态。固定u分层只是测量取样，不是固定线上动作位置。
每个状态比较少量相对跨度（小/原/大）及gamma（弱/原/强），测上述局部读数。

新增问题不是再证明余弦有动态范围，而是：

- 固定噪声层内，敏感度能否识别“大步风险”和“增加引导仍有效”？
- 相比仅噪声位置、仅R、仅位移幅度，方向敏感度是否提供额外排序信息？
- 条件均值/局部响应的判断能否转移到实际随机一步，而不是只拟合自己定义的E？

分图留出、以图为统计单位；已有六图只能称开发诊断，不能再称未见确认。
连续读数和动作效果同时报告，不只报分类准确率。若所有图都选相同动作，
它支持固定动作而不是个体自适应。没有可用增量则停止赋予该读数控制权。
先输出逐查询成本清单再执行，不能默认9个候选的测量免费。

### II：控制作用的最小拆解

只有I通过可靠性和动作信息检验，才冻结首版规则。先分别运行：

| 臂 | 步长/区域分配 | gamma | 回答的问题 |
| --- | --- | --- | --- |
| 原C、强固定F | 固定 | 原值/固定脉冲 | 基础与强固定对照 |
| 固定阶段曲线 | 开发冻结，不读当前状态 | 开发冻结 | 是否只是噪声阶段效应 |
| 状态选步 | 当前风险与预算决定 | 原值 | 选步本身是否有效 |
| 状态引导 | 固定 | 当前物理响应与风险决定 | 缩放本身是否有效 |
| 联合 | 同一个当前状态决策 | 同左 | 两者结合是否有净收益 |

每臂均按真实全部NFE匹配，不按接受点数匹配。方向项另作移除/幅度匹配消融；
跨图状态互换只用于诊断信息来源，不是可部署方法。不能因臂数增加就全部展开大扫描。

若额外探针成本过高，优先检验用已接受步骤共享读数或经验证的低成本代理；
若无法在成本内保持效果，应如实得到效率负结论，而不是漏计探针。

### III：冻结后确认与效率边界

在未参与任何本轮选择的新图上确认；A27的十二图此后已成为已见数据。
保留每图两个seed，以图像聚合置信区间；不按seed挑结果。
首先在同一任务、不同初始网格验证控制是否仍依赖当前状态，随后才扩任务/数据集。
网格改变时必须重新满足参数映射契约，否则无法把差异归因于调度。

分别比较总预算曲线与质量容差下的调用数。主指标PSNR正向，沿用平均SSIM退化≤.002、
平均LPIPS退化≤.005；逐图退化与物理一致性同时报告。另要求相对强固定与阶段对照
存在状态增量，不能仅胜原C就宣布开题成功。置信标准和比较家族在看结果前冻结。

## 7. 目前可作的判断

开题的控制目标仍是可研究、可实现的目标，但当前没有已验证的状态控制收益，
也没有NFE节省证据。合理的下一步是验证“当前状态对候选动作的响应”，
而不是继续报告固定位置加倍的提升或换一个未经验证的余弦公式。

实现顺序是状态—动作响应诊断、分离控制、联合与独立确认。
读数可靠不等于能预测动作，能预测局部动作不等于最终画质更好，最终画质更好
也不等于效率更高；每个跨越都要独立证据。
