# 开题路线复核、阶段结论与最小验证清单

2026-10-20。根据开题报告全文、最初对话、历史阶段报告及A0–A22证据重新梳理。
本文件是研究判断和后续实验设计，不表示启动新GPU实验，也不修改已完成实验的判据。

后续用户明确固定步数优化采样位置、最多五个实验得出初步结论。具体实施以
[A23–A27冻结队列](experiment_cards/A23_A27_fixed_count_state_positions_20261020.md)为准；
本文件E0–E4是科学证据链，不额外叠加为五轮之外的新实验。当前优先同预算质量，不减少S。

## 1. 明确结论

**选题可以继续，但属于“实现路径有基础、核心收益尚未成立”的有条件可行方案。**
目前不能说开题创新已经成功，也不能由A21/A22推断整个状态感知自适应采样不可行。
若严格坚持“原始相邻余弦直接决定步长、无额外成本评估所有候选、仅靠限幅保证收敛、
显著减少整个ZAPS推理NFE”这些强表述，现有证据不支持，必须修订。

需要保留的主线是：

    物理观测偏离 + 局部更新方向变化
        → 判断当前噪声阶段的数值/重建风险
        → 在固定总预算下分配采样调用
        → 再检验同质量下是否可以降低总成本

引导权重调节是辅助变量，不应取代这条主线。A16–A22主要回答固定修正与权重动作问题，
对寻找强对照和排除错误控制映射有价值，但不能替代步长分配的验证。
上一轮把进入步长实验描述成“换研究方向”不够准确：开题原本就研究步长自适应；
最初“先不调整调度”是先验证指标的阶段安排。当前只讨论恢复主线，不自动启动实验。

## 2. 开题原文究竟要求什么

来源：[开题报告](</Users/liziyue.22/Desktop/论文文档/研究生学位论文开题报告-李子玥-2240502010.pdf>)。
PDF实际第3页为摘要，第7页为研究内容与目标，第10–12页为技术路线与创新点。

| 开题内容 | 应当用什么实验兑现 | 当前状态 |
|---|---|---|
| 双重状态指标：更新方向稳定性、物理残差 | 可重复测量，并在相同噪声阶段提供不同的信息 | 可测性已有支持，独立指导价值不足 |
| 统一评价函数、贪心选择局部步长 | 指标能区分候选步长的代价/风险，且调用成本被计入 | 尚无已验证的完整闭环 |
| 局部误差控制、稳定性机制 | 范围/变化率/端点/预算有明确契约，实测不异常 | 有回放与粗细步技术基础，未完成完整控制器 |
| 步长与引导权重协同 | 先分别验证两个控制变量，再用消融证明联合价值 | 固定权重动作有收益，状态权重收益未建立 |
| 零样本、轻量、无需额外训练 | 不更新预训练去噪器，不训练需GT的控制网络，逐图优化与控制成本明示 | 可实现；此前岭回归仅可作离线诊断 |
| 同质量下显著减少NFE | 完整流程质量—成本曲线、实际耗时、独立图/任务确认 | 尚未完成 |

原文的“无需训练”与ZAPS逐图优化有术语张力。建议明确写成：
“冻结预训练扩散网络，不训练额外控制网络；保留并计入ZAPS的逐实例ζ/D优化。”
若要求连逐实例优化都取消，将是另外的方法，不能继续把原300-NFE ZAPS视为同一流程。
ZAPS原文Algorithm 1和§3.1–3.2明确包含逐轮更新ζ/D，而不更新预训练score网络。
参考：[ZAPS原文](https://arxiv.org/html/2407.11288v1)。

## 3. 整个过程真正得到的结论

### 3.1 历史观测和早期控制

历史20图FFHQ SR实验中，末步残差与最终PSNR相关约−0.82至−0.84；余弦较弱且符号依赖
噪声设置、对象和聚合方式。去掉最终采样注噪使余弦转正，却没有使它成为更可靠的PSNR信号，
LPIPS反而变差。这些旧实验是优化300+额外采样30=330 NFE，不与后来300 NFE直接合并。

早期v1–v3曾出现高噪声区耗尽小步、终点未到t0、训练/采样噪声设置不一致、参数索引等问题。
修复后某些10图参考曲线方案有小幅PSNR改善，但没有隔离方向贡献，部分LPIPS退化；
跨测量域或ImageNet的既有映射也未获得可靠综合收益。
这些结果否定对应实现/映射，不能证明所有状态反馈都无效。

### 3.2 A0–A2b：从“曲线变化”到“测量对象明确”

被动观察器可以不改变原输出地记录完整轨迹。区分了含噪更新、clean增量、条件均值更新、
同一步先验/引导夹角，以及实际物理修正q的相邻方向变化；它们不是同一个余弦。
后期q方向更一致、残差和q幅度更低，支持阶段描述。

固定t的q方向扰动可测；但相邻q方向变化/路径归一化量没有成为全阶段统一正向敏感度代理。
“余弦低→局部敏感度高→应该加步”这一连串推断尚未成立。

### 3.3 A2c–A2d：简单减弱与刷新方向未获稳健支持

减半/关闭引导的旧局部实验未建立稳健综合收益；中后期往往使物理loss和质量恶化。
同时间刷新方向相对幅度匹配对照也未获稳健支持。
这限制了“看起来不稳定就减弱引导”的直接规则，并不等于所有状态权重控制无效。

### 3.4 A3–A6：细化动作有潜力，但增加了调用

在明确的引导映射和噪声桥接下，局部粗细步对照可构造，固定后期细化在小样本最终输出上
得到约0.1 dB量级PSNR收益，并有感知改善。说明某些细化动作可能有价值。
但候选部署增加一次网络评估，且主要是固定位置收益；尚不是“从别处省一次调用再细化”
的等预算重分配，也不是状态指标已经选对了位置。
A3的区间G_t与引导分配是明示的诊断约定，不能自动当成任意变网格ZAPS的连续时间定义。

### 3.5 A7–A15：原被动指标增量不足；精确响应有线索但成本高

A7的q余弦/三步变化量和A10的clean粗糙度，没有在原固定转移协议下稳健优于物理特征及
阶段参照。负结果对应那些特征、目标和小样本模型，不能无限泛化，也不应重扫窗口追分。

A11/A12暴露小扰动差分的精度问题；A13/A14通过IEEE精度控制获得可用固定t响应，
沿q与正交方向存在可测差异。A15保留了PSNR增益预测的探索性线索：两层MAE相对物理特征
下降约22%/25%，原联合判据仍未通过。它不是重建PSNR提升22%/25%。
每状态的完整响应测量约10次网络调用，当前只能作为离线机制量，不能免费加入轻量控制器。

### 3.6 A16–A20：固定末端修正有收益，状态规则未胜出

末端多评估一次后，固定F1/F2得到PSNR增益；但F2在A18新图队列LPIPS平均增加0.00718，
超过用户0.005保护线。经验位移与q的消融帮助定位质量取舍：移除额外先验位移后，A20在
新图队列保留约95%的F1 PSNR收益，消除约82%的LPIPS退化。
这些是固定动作/机制发现，部署仍为301 NFE。状态投影保护与饱和到上界的线搜索没有
显示超过强固定动作的增量，不能计为状态创新。

### 3.7 A21–A22：同预算固定收益成立，测试动作集没有状态选择余量

A21原最后一步的固定、物理、完整状态都选gamma2；迁移队列PSNR +0.129699 dB，
SSIM +0.002487，LPIPS +0.000288，均300 NFE。状态增量和GT诊断oracle余量均0。

A22在五个原阶段分别做一次gamma .5/2引导pulse，运行完整剩余原轨迹；每候选300 NFE。
开发选出的T319_G2在迁移队列仍最佳：

| 相对原C的均值变化 | 开发3图×2seed | 迁移3图×2seed |
|---|---:|---:|
| PSNR dB | +0.263632 | +0.231432 |
| SSIM | +0.009113 | +0.007514 |
| LPIPS | −0.004132 | −0.004798 |
| 物理loss | −0.042759 | −0.037711 |

12例的三项质量指标均改善，且每例13个动作中PSNR最大者全部是T319_G2。
所以在这个有限动作集中，不存在任何状态选择器可以取得的正PSNR增量；两个队列的诊断
oracle余量均0。t903局部约0.017 dB选择余量不能忽略全动作的强固定对照。
这不涉及步长插入/合并，也没有测试多步协同反馈，不能扩展为否定开题整体。

本地已核验GitHub A22轻量归档29文件、12例run SHA/已记录门控、调用记录及全部摘要/
离散oracle重算；未在Mac重放服务器原张量或CUDA。
累计队列A2a含恢复至A22为7200 method+3608 diagnostic=10808 NFE，更早单图/历史实验另列。
这些投入不是已证明创新的百分比，不再用“45%”替代科学状态。

## 4. 当前双状态体系的准确定位

保留已可重复测量的定义，不继续搜窗口/频段制造相关性。

给定z_k为原clamp后clean估计，m为测量元素数，白噪声标准差sigma_y已知：

    R_k = ||y-H(z_k)||_2 / (sqrt(m)*sigma_y)
    a_k = RMS(q_k)
    n_k = q_k / ||q_k||_2
    c_k = <n_k,n_(k-1)>
    T_k = ||n_k-n_(k-1)||_2 = sqrt(2(1-c_k))
    Omega3_k = (T_k+T_(k-1))/(u_k-u_(k-2))

其中u是基于本模型实际sigma_eff的归一化log噪声进度。
q是当前实现实际施加的预条件测量修正，不是已经认证的完整latent似然梯度。
近零q方向标不可分辨，不填造余弦；T与c是同一信息的不同表示，不算两项独立证据。
Omega表示单位噪声进度的近期方向变化，既不是严格曲率，也不是Hessian或实际局部截断误差。
q只覆盖物理修正，不能单独代表完整先验+引导采样更新的几何；必要时记录条件均值更新作
解释性对照，但历史证据不允许预先宣称它比q或clean更好。

物理状态回答观测解释程度；方向状态拟回答当前修正场变化是否提示风险。
还必须有u、当前跨度、a和clip作上下文：这些量随阶段共同变化，仅比较全程相关性不够。
检验要落在同噪声阶段、实际有竞争的动作上，并比较加入方向前后的实际收益。

R不应被强迫每步单调下降，也不应被逼向0；R≈1只是噪声量级参考，不是本依赖估计量的
普遍停止阈值。方向一致也不保证方向正确，更不保证下一步重建会变好。

| 内容 | 处理 |

| 引导权重调节 | 作为第二阶段辅助变量，先锁定强固定对照 |

| qCos/Omega直接当敏感度/曲率 | 停止这种等同解释 |
| c低就减权、残差大就加权 | 不能直接部署，已有具体负结果，须有阶段/动作验证 |
| A21末步与A22五点单pulse的选择器 | 关闭对应动作集，不改阈值/扩系数追机会 |
| GT拟合的岭回归作最终零训练控制器 | 不采用；只用于离线探索，需明确标注监督校准 |
| 同一步评估多个候选却不计其score调用 | 不允许；若仅用状态作廉价预测，要验证预测能力 |
| 限幅即可保证整个采样收敛 | 改为有界调节、预算和端点保障及经验稳定性；理论收敛需另证 |
| 零样本/不更新去噪器 | 保留；ZAPS逐实例优化与控制费用仍全部计入 |

统一代价函数可以是启发式决策准则，但原始残差与余弦单位不同，任意加权不等于统一
误差空间，也不等于画质最优。更稳妥的初版是：噪声阶段为参考，误差/变化风险作限制，
在剩余预算与端点可达的条件下选择跨度。风险估计本身仍要实验验证。

开题参考的[Gotta Go Fast](https://arxiv.org/html/2105.14080v1)采用成对数值近似估计误差并
支付额外score成本，可以借鉴误差缩放和预算意识；其生成结果不替代当前反问题证据。

## 6. 还缺的最少实验：按门槛串行解锁

以下为方案，具体节点/规则/预算在运行前另卡冻结；本文件不凭空给出未实现入口或GPU命令。
不重复已失败的旧目标/窗口/映射，也不一次展开所有数据集、任务和参数。

### E0. 改步长的数值契约和原网格等价，技术前置

- 明确ζ/D在噪声坐标中的索引/映射，以及改变区间时物理修正如何分配；仅插值D/ζ并不
  自动保证不同跨度的有效引导作用可比，A3已有冻结场匹配是可复用的诊断基础。
- identity网格、关闭控制时重现原输出/参数/预算；保持999→0和真实末端输出语义。
- DDPM原注噪不直接关闭；粗细比较使用边际正确的耦合噪声。若仅共享seed而非同一路径，
  明确称共同随机数，不能声称Brownian路径相同。
- 固定总调用数和剩余端点约束，不靠预算耗尽后无界大跳“成功终止”。

通过只表示接口可信，不能增加科学收益进度。

### E1. 真正的同预算调用重分配，回答动作有没有净价值

先只控制步长，不同时改变引导权重。以少量预声明的“一区间细化、另一区间合并/省评估”
构造总30调用的完整轨迹候选；这是新动作，不是A22的q缩放，也不是A4–A6的免费多一步。
首先在原开发3图×2seed做机制检验，保留旧强固定300-NFE参照和相应固定重分配参照。
明确哪些对照仅用于分离步长效应，哪些用于比较最终综合质量，避免把固定权重收益算作步长收益。

复用前270调用、只替换最后30调用可以快速筛选，科学候选仍总300；所有分支实际新计算
作为diagnostic费用列出。它只能说明冻结原优化结果后的最后一轮可控性，不能替代全流程。
评价最终PSNR/SSIM/LPIPS/物理loss及成本，而非只看粗细张量距离或下一时刻clean。

判定：必须存在净有益且随案例/状态有区别的调用分配机会。诊断oracle只作上界；若相对
强固定重分配无有用余量，则停止这个动作定义，不继续造选择器。可沿用0.01 dB作为
探索性余量筛选线，但它不是文献标准或正式论文成功门槛。

### E2. 状态是否真的能选对动作，回答方向是否有独立价值

只在E1通过后解锁，可与E1共享全部分支和状态，不重复GPU采集。
目标改为“同预算重分配后的最终净收益”，不是A7的额外中点收益或A22的单pulse收益。
比较阶段/跨度参照、阶段+R+a、再加入T/Omega；按图分组，同t检验，保留全部负例和取舍。
先验证能否区分受益/受损或排序有用动作，不把预测MAE下降当实际重建收益。

最终规则须用当前及过去状态，不能看未来轨迹后回选更早位置；不以GT训练策略网络。
GT可用于离线诊断和开发评价，但若用GT校准阈值/模型必须披露，不能宣称完全无标注设计。
当前被动T/Omega不是已通过的预测器；E2是该新控制目标的有限验证，不是旧失败目标的重跑。
若方向不胜物理/阶段参照，应删减对“双指标必要性”的主张，不靠换窗口追结果。

### E3. 同总NFE的因果在线闭环，回答状态引导能否改善重建

在相同步长机制、参数映射、预算和输出约定下比较：

1. 原固定采样及已经确认的强固定改进参考；
2. 只按噪声阶段分配的固定规则；
3. 仅物理状态的规则；
4. 物理+方向状态规则；
5. 打乱方向状态的诊断对照，用来检查是否真的在使用当前状态。

所有探针、候选尝试、额外score和拒绝重算计入总方法NFE，不能只令接受步数相同。
控制器本身的计算和物理算子调用体现在实际耗时中。方向臂必须在相同成本下优于物理臂
和强固定臂，而不只是优于原始弱基线；还应观察实际动作是否因状态而异。
冻结规则后评价保留样本；已多次看过的00020–31不能重新宣称全新确认集。

PSNR作为主指标，用户已固定平均SSIM降幅≤0.002、LPIPS升幅≤0.005，逐图退化单列。
将数值地板、开发筛选线与正式非劣/收益标准区分并提前冻结。
若物理+方向不胜物理/强固定，双状态控制价值未建立；不能改口称曲线可解释就算成功。

### E4. 开题效率目标与论文确认，最后解锁

- 通过E3后，运行从头的完整ZAPS流程，统计所有轮次总NFE及实际时间，不止最后一轮。
- 冻结前270、最后30→20只把总300→290，节省3.33%，不是全流程节省33%；不能据此
  声称显著降低整个ZAPS成本。若要更大节省，需在更多轮次生效或减少有效轮次并单独消融。
- 给出至少若干预定总预算的质量—成本曲线，以同质量更低成本或同成本更好质量评价；
  额外候选试探/敏感度探针成本可能抵消省下的步数，必须实际核算。
- 先冻结一个FFHQ SR控制器，再在未用于开发的固定图像名单确认；追加种子检验稳定性。
  图像数在卡中事先决定，小样本不宣称大规模统计结论。
- 扩到至少另一种退化和另一数据分布；若保留开题的多任务/跨数据集主张，需补对应任务，
  不能以一个SR任务的重复轮次代替。DPS等外部对比在预算/算子/指标口径对齐后进行。
- 步长主效应确认后，才加入状态权重调节，做步长单独/权重单独/联合消融。

E0–E3是判断核心主张所缺的实验链；E4是兑现显著效率、独立确认和泛化主张的必需部分。
不建议现在先扩大固定T319_G2的数据量而延后E1–E3，除非明确把工作降格为固定策略研究。

## 7. 最终判断与论文表述边界

- **可以实现的部分**：冻结去噪器的规则控制模块、可测双状态、明确的预算/端点约束、
  指定映射下的粗细步和固定预算分配，以及完整的实验闭环。
- **目前不能认定的部分**：余弦就是局部误差、双指标一定胜单指标、加限幅就理论收敛、
  无成本多候选贪心、状态策略已带来重建/效率/跨任务收益。
- **开题能否完成的结论**：技术实现有条件可行；作为性能创新能否成立，要由E1–E3决定，
  现阶段尚不够支撑原创新点已经成立。若E1–E3通过，可沿原题继续，再兑现E4；若不通过，
  应与导师讨论收缩创新主张或调整研究问题，固定0.23 dB收益不能替代状态感知贡献。

不再把原“保证收敛、局部最优、大幅加速、显著泛化”等设想写成事实。
较准确的研究目标是“预算约束下，基于物理一致性与方向变化的规则驱动自适应采样，
验证其相对强固定与物理单状态策略的质量—成本优势”。
