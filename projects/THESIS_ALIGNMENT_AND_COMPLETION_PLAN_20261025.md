### 前期实验的正向与负向价值

- 被动轨迹和重放门控建立了指标可测性与可复用协议；残差与画质相关不等于可用的控制律。
- A22等固定位置倍率干预证明存在可利用的动作空间；不能证明该位置由当前状态决定。
- A7/A10、A26–27及后续几何诊断没有建立余弦/粗糙度的独立收益。
  它们为否定“方向变化大就一定应多采或减弱引导”的简单假设提供了边界证据。
- A33之后的响应倍率把当前状态映射到真实控制动作；A36则揭示其噪声风险与时间规则混淆。
  这是有用的机制分析，尚不是完整方法优越性的证明。

负结果可以支撑消融与设计动机，不能单独替代正向方法验证。
更不能把普通方向余弦、随机路径有限差分或本轮响应/噪声权重改名为“真实曲率”。

## 三、与开题逐项对照

| 开题内容 | 当前证据 | 可以写的范围 / 还缺什么 |
|---|---|---|
| 外在物理一致性 | 已计算R、残差方向和动作响应 | 可构建物理状态；不能由残差更小直接推出画质更好 |
| 内在轨迹稳定性 | 多种余弦、方向变化和局部响应已测 | 可作诊断；未证实曲率代理对决策有独立贡献 |

| 局部统一代价 | A37仅有一个标量倍率的正则目标 | 局部凸二次解析解；不是全程采样/步长统一代价 |
| 自适应步长与采样位置 | 曾做机会和局部干预诊断 | 尚无可靠在线调度收益，不能写成已完成创新 |
| 步长与权重联合控制 | 当前只在固定网格调权 | 尚未建立联合体系 |
| 降低NFE并保持质量 | 当前科学臂300 NFE | 等NFE是公平性，不是节省NFE；额外H运算也要计耗时 |
| 收敛/鲁棒性 | 有数值门控、倍率界限和失败留档 | 有限终止、倍率有界均不等于正确收敛定理 |
| 零样本 | 新控制器不训练UNet/策略网络 | 原ZAPS逐图ζ/D优化仍存在且计费，不能说完全无需优化 |

原版ZAPS已逐图优化时间步相关权重和波域参数。
新贡献不能简单写为“首次调整权重”，应定位为：利用当前残差、动作响应和噪声尺度，
构建可解释的在线校正，并验证何时它比时间/噪声先验有额外价值。
参见[ZAPS原论文](https://arxiv.org/abs/2407.11288)。

## 四、A37：噪声如何进入状态到倍率的传导

定义当前clean估计z、原ZAPS引导位移q：

    r = y − H(z)
    v = q / sqrt(alpha_bar_t)
    a = H(z+v) − H(z)
    R = RMS(r)/sigma_y
    c = cos(r,a)
    b = ||a||/||r||

这里c是同一步物理残差与预测响应的余弦，不是相邻时间步方向余弦。
a采用现有identity-clean响应近似，不是完整去噪器Jacobian，
也不预测后续所有随机步对终局画质的影响。

旧规则近似最小化||r−gamma*a||²，raw_gamma=c/b。
新规则固定lambda=1，最小化：

    J(gamma) = .5||r−gamma*a||² + .5*lambda*m*sigma_y²*(gamma−1)²
    raw_gamma = (dot(r,a)+lambda*m*sigma_y²)/(||a||²+lambda*m*sigma_y²)
              = (c*b*R²+lambda)/(b²*R²+lambda)
              = 1 + w*(c/b−1)
    w = b²*R²/(b²*R²+lambda)
    gamma = clip(raw_gamma,0,2)

另保留预期J改善不足1%时回退1、响应不可辨时保持1的规则。
sigma_y是已知的**测量噪声**，不同于扩散时间t的噪声尺度。
锚点1对应原ZAPS。响应相对噪声弱时，w小，降低偏离原方法的幅度；
响应强时更多采用局部拟合建议。较高sigma使raw_gamma向1回缩，
若旧建议低于1，回缩反而会提高倍率，不能表述为一律减小引导。

这是可解释的工程风险正则；w不是真实SNR、校准置信度或内在轨迹曲率。
lambda=1、上限2、1%回退均在看A37结果前冻结，非理论最优常数。
本轮不扫描，不强行把终局R推到1，也不通过GT在线选择倍率。

噪声加权保真项与先验正则的平衡在图像复原中已有成熟依据，
例如[DiffPIR公式1](https://arxiv.org/pdf/2305.08995)明确含sigma_n²。
本轮具体的“向原ZAPS倍率1回缩”属于我们提出的局部工程模型，
不能声称直接由DiffPIR推出，更不能把二次正则本身当作全新的理论。

### 必须分开的对照

| 代称 | 读取当前目标图状态 | 读取真实测量sigma | 要检验什么 |
|---|---|---|---|
| C | 原ZAPS | 原基线协议 | 质量参照 |
| OLD | 是，旧c/b | sigma只用于R读数 | 旧规则的噪声风险 |
| TIME | 否，旧冻结表 | 不据sigma改表 | 原时间规律能解释多少 |
| REG | 是，新正则 | 是 | 噪声约束的状态控制 |
| BLIND | 是，同一新正则 | 否，固定假设.05 | REG−BLIND区分噪声信息价值 |
| TIME_NOISE | 否，旧开发图的平均响应二次目标 | 是 | REG−TIME_NOISE区分当前状态价值 |

TIME_NOISE不是新REG路径上重新收集的精确匹配时间表，正向状态差仍需更强确认。
REG若与TIME_NOISE相同，只能支持噪声知情规则，不能支持目标图状态独立有效。
状态策略不必每张图、每项指标都超过固定规则，但必须至少证明额外信息、
跨条件稳健性、减少重调参或效率中的一种实际优势，不能只有名义上的“动态”。

A37复用A36全部观测/PRE及原随机噪声；18case新增诊断1440 NFE、无基线重训。
sigma=.05时REG=BLIND，直接别名复用，避免180次冗余调用。
本轮科学臂仍为270+30=300，三个噪声条件必须同时报告PSNR/SSIM/LPIPS与逐图风险。
三档REG−C均满足PSNR≥+.05、≥4/6图正向及既定均值画质保护线，才标为质量候选。
状态/噪声额外价值另判，不随总PSNR改善自动通过。
这些图现在属于开发诊断集，不能再称新规则的独立测试集。

## 五、哪些补充能把材料推进到论文主线

### 必要的最小证据链

1. **机制与消融**：A37/A38已定位主要取舍，但未通过全条件保护，当前正则路线停止。
   A38b已完成；下一项是共同决策中心的局部增强风险验证，不再扩当前正则扫描。
   分清REG−C、REG−BLIND、REG−TIME_NOISE，不继续只积累对C的增益。
   若仍无状态增量，停止宣称当前状态优越，保留可解释的负结论。
2. **冻结后的新图确认**：机制通过后另选未用图与固定seed列表，
   建议12–20图×两seed作为可操作的下一阶段规模，预算单独制定。
   这是研究规划，不是学校对硕士论文的最低样本要求。
   在看测试结果前冻结控制器，逐图报告、按图像簇汇总区间，避免把多seed/多噪声当独立图像。
3. **更强时间对照与超参敏感性**：比较同样知道sigma、允许公平开发校准的时间规则；
   必要时在独立开发图上收集REG路径参考，而不在测试图拟合表。
   仅做有限、预先说明的lambda/上限敏感性分析，不能反复看测试结果直到变好。
4. **物理协议和跨任务**：正式主结果需锁定前向/伴随、值域、测量噪声与指标口径，
   对legacy开发设置明确披露；再补一个退化任务（如高斯去模糊）及模型/数据迁移。
   开题列有FFHQ、ImageNet、多任务，目前不能只用FFHQ超分辨率覆盖全部承诺。
5. **成本与可视化**：报告实际总NFE、原逐图优化开销、额外算子时间、整图/固定局部图，
   展示PSNR与LPIPS的取舍及最差案例。相同NFE不能自动当作相同运行时间。

### 两条论文范围路径

**保留原开题完整范围：** 在上述权重模块有效之后，还需至少一个有实证支持的步长/
采样位置模块。用同预算比较最强固定调度与状态调度，再做质量—NFE—时间曲线，
将步长、权重、联合版本消融。离散点插值、ζ/D索引、端点与随机耦合都需明确。
当前不宜同时改调度，以免无法解释A37结果；先把反馈权重这一环验证清楚。

**收敛为引导控制主线：** 可与导师讨论将范围调整为
“面向含噪图像反问题的扩散采样状态反馈与引导自适应方法研究”。
以物理状态、动作响应、噪声风险为体系，完成控制律、消融、跨条件和多任务验证。
这个方向与开题的权重自适应直接契合，但需明确放弃尚无证据的曲率控制和NFE节省承诺，
不能悄悄把它写成原三项创新已经全部完成。

## 六、A37运行前规定的判断分支（保留原边界）

| A37观察 | 允许结论 | 下一步 |
|---|---|---|
| 质量保护恢复，并有REG−TIME_NOISE优势 | 状态/噪声控制候选有开发证据 | 冻结新图确认与更强时间对照 |
| 质量恢复，但REG≈TIME_NOISE | 噪声知情规则有效，图像状态独立价值未证 | 改善状态的动作预测能力，不扩“状态成功”叙事 |
| 感知改善但PSNR退回C附近 | 正则产生质量取舍，尚无整体优势 | 报告Pareto取舍，有限开发校准后再决定 |
| 仍显著损害画质或无稳定收益 | 当前局部响应/目标不充分 | 检查响应近似与目标；不强行加入更多指标凑体系 |
| 一致性/身份门控失败 | 尚无算法结论 | 修正具体接口，保留失败及实际成本 |

能够支撑论文的关键是明确的问题、可证伪的控制机制、可靠对照和足够的独立验证。
当前已有前两者的研究基础，后两者仍需补齐；不能将A37局部正向信号写成完整方法验证。
