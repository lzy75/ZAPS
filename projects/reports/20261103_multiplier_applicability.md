## 统一符号与适配的必要条件

m为干净预测，q为宿主方法给出的干净坐标校正，r=y−Hm，d=Hq；M为实际观测元素数。
当前噪声权重 omega=(1−M sigma_y²/||r||²)_+。
当前倍率 gamma=omega*positive(<r,d>)/||d||²，是沿q拟合omega*r的解析投影，不是后验不确定性估计。
q若在扩散状态坐标，必须先按宿主更新关系转换；DPS中使用的是同t恒等响应代理，不是真实下一次去噪器响应。

原投影具有尺度抵消：q乘任意正数c会令gamma除以c，最终gamma*q不变。因此保留参数文件不等于保留原引导幅度；ZAPS正的全局zeta幅度在这类投影位置会被抵消，D仍可能影响方向，前9轮学习/轨迹也仍有作用。

对近端校正，宿主原目标为 min_q .5||r−Hq||²+.5rho||q||²。rho不是可删除的任意上限。
把它沿同一q保留后，A80目标为

    min_gamma>=0 .5||gamma*d−omega*r||²+.5rho*gamma²||q||²
    gamma = omega*positive(<r,d>)/(||d||²+rho||q||²).

精确近端方程 (H^T H+rho I)q=H^T r 给出 <r,d>=||d||²+rho||q||²，所以gamma=omega。
这解释了如何保留DiffPIR原目标；不保证真实重建改善。该恒等式只用于原生近端q，不能将任意ZAPS/DPS校正冒称为相同近端解。
新适配对DiffPIR本质上是噪声感知阻尼，不含新增响应方向计算；若仍弱于基线，应保留原DiffPIR，不继续扫描系数。
来源：[DiffPIR §3.2](https://arxiv.org/html/2305.08995)，原代码固定提交2a9898129a1b274131b98746e5b364bc20adc1e1；噪声修正目标是待验证改造。

## 使用边界

| 条件 | 当前处理与适配要求 |
|---|---|
| 线性观测、明确的校正向量 | 可复用残差/响应统计；明确坐标、H、伴随、噪声口径；不需额外NN |
| 梯度引导，如现DPS/ZAPS | 当前投影已验证部分配置；会重新确定幅度，需分别对原基线和固定倍率表比较 |
| 已解正则数据子问题，如DiffPIR | 原投影有冲突；A80保留已知正则能量，不引入拟合系数 |
| mask/随机补洞 | 只按实际观测空间计算噪声能量；零填充未观测元素不能计入M；需匹配y的实际噪声生成方式 |
| 相关/非均匀噪声 | M sigma²须改为对应观测度量的噪声能量，例如欧氏度量tr(Sigma)，加权度量tr(W Sigma)；不是直接套标量sigma |
| 非线性观测 | H(m+gamma q)不再等于H(m)+gamma Hq，需响应线性化或实际算子评估，当前公式不能直接当精确最优解 |
| 后验MCMC，如DAPS | 需区分观测漂移、先验漂移与随机项；改变状态相关漂移通常也改变目标分布，另立实验，不沿用原保证 |
| 残差接近噪声能量 | omega可能很小或为0；m依赖y，残差噪声并非独立，故该噪声扣除是启发式而非无偏风险/置信度 |

当前框架中的“通用”应指可共享的统计接口与宿主目标适配原则，不能解释为所有方法使用同一gamma公式都有收益。
