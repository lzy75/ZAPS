## 2. 数值解决不等于新增状态收益

新U和V均每例30/30解决，合计600个FFT动作；新U本身300/300。
旧U Gaussian33/150、Motion44/150，共77/300=25.67%解决，其余使用原q回退。
377次输入VJP=新U300+旧U77；V和C不做该输入VJP。
表中C resolved=0表示该臂不构造这个响应传感器，**不是C基线0步成功或数值崩溃**。

原空间double真残差和全部FFT实际步骤通过1e-5门控，补上了A61只测合成RHS的缺口。
但从旧U变新U既提高求解覆盖，也改变了哪些时间点实际执行U而非q，
因此不能把相对旧U的所有画质变化归结为纯舍入精度改善。
