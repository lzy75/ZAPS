## 3. A59：局部几何有初步信息，尚无几何控制增益

状态构造仍为固定t下的r→v→u；新增几何使用同t两尺度正负扰动，读取u方向变化率Omega和相对幅度敏感度S。
预测器的GEOMETRY特征是物理R/g加Omega/S，有限尺度非线性B虽有测量，但没有进入此预测器。
目标是最终PSNR差DeltaP=P(gamma1.5)-P(gamma0.5)，不是PSNR本身或“提升百分比”。
训练/诊断按同task、同t匹配并排除同一图；只有5个复用图像簇，30个状态不当作30张独立图。

|PSNR剂量差预测|STAGE纯时间|PHYSICAL：R/g|GEOMETRY：R/g+Omega/S|
|---|---:|---:|---:|
|整体MAE/dB|0.193656|0.206574|0.166144|
|SR内MAE/dB|0.071963|0.075986|0.072206|
|IP内MAE/dB|0.315348|0.337162|0.260083|

整体相对STAGE减少14.21%、相对PHYSICAL减少19.57%，4/5图优于PHYSICAL，30/30状态可读，达到了原卡的开发候选判据。
信号主要来自IP；SR相对STAGE略差，不能称两任务均有预测增量。SSIM/LPIPS的预测也未一致改善。

**额外事后只读诊断，不改A59判定：**用已存的LOO预测正负强行选择gamma=.5或1.5，GEOMETRY与STAGE总体都猜对22/30个强弱次序。
GEOMETRY对应的单步缓存终局PSNR平均相对不改gamma=1仍为-0.01751dB（SR-0.02652，IP-0.00850）。
它虽比这项二选一STAGE诊断少损失，但不是正向在线控制收益，也不是把这些单步动作串起来后的轨迹结果。
因此不能从MAE改善直接部署控制器；不改gamma=1必须作为可保留动作，强弱差本身也不足以判断二者是否都差于不改。

现成例子：IP t319时gamma1.5相对U平均PSNR+0.13944dB，但t54时gamma.5与1.5分别-0.32071/-0.42310dB。
同一任务也不是所有时点放大或缩小都好。这里是诊断现象，不能按见到的GT将固定时点规则回填为状态算法。

## 4. A60：当前方向不能简单固定间隔复用

每一步都更新当前物理v和目标长度K||v||，仅将u方向改成每2/4步刷新，首末必更新。
所有路径完全解决，质量损失不能解释为CG未解决。

|相对CURRENT的终局变化|SR PSNR/dB|IP PSNR/dB|合计输入VJP|
|---|---:|---:|---:|
|每步CURRENT|0|0|300|
|LAG2|-0.937996|-2.249631|160|
|LAG4|-5.480066|-7.658574|90|

两种lag在10/10例都降低PSNR，SSIM/LPIPS也明显退化，均未达到质量保护线。
同场总计时72.22/58.27/54.71秒是共享服务器、固定顺序和诊断写盘下的观测，不当作生产加速比例。
可写：在当前旧图协议中，只保留当前物理幅度、简单复用旧方向不足，近期响应方向信息有实际价值。
不可写：这已经证明每一步当前Jacobian不可替代。缓存还混入旧x、t和v，尚未做“冻结J作用于当前v”的独立对照。
也不能因LAG2仍优于C就把它叫质量保持的低成本方案；它明显差于当前可用U。
