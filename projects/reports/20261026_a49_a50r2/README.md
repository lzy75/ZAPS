## 2. A49：为什么前一轮的反馈没贡献

LOCAL用新的局部目标J挑选t319倍率；LEGACY为原策略；TRUST再加rho可靠性筛选。
SR中3/5例、IP中4/5例改了倍率，**这7例均是J更优但终局PSNR更差**。
平均LOCAL−LEGACY分别−0.398、−0.422dB；IP的LPIPS还恶化0.00917。
Gaussian/Motion没有改动作。TRUST对LOCAL改变**0/20**动作，不能把对C的正收益称rho增量。
IP中存在3个可行但不可靠的候选试探；最终选中的动作仍通过筛选。不能说所有试探都可靠。

有效结论：在这批干预中，更可信的局部目标拟合也没解决目标与最终画质的错位。
这不证明所有可靠性控制无效，也不支持继续扫描同一个rho阈值。

## 3. A50r2：比较的是什么

同5张已用开发图00446/00559/00608/00873/00951，四任务，seed1000，已知sigma=.05。
重用原先270次调用，最后30个原时间点全部重新计算反馈，未改变采样位置或步数。
基线是这套明确配置的本地ZAPS参考（继承A40，LR=.01、exact伴随、unit观测），不是作者1000图原表复现。

| 名称 | 实际作用 |
| --- | --- |
| C_NATIVE | 原本地实现、原数值策略、倍率1，回放与父输出相符 |
| C_IEEE | 关闭TF32并启用所需计算图的匹配基线，倍率1 |
| PROX_Q | 用测量线性求解得到的目标v确定原ZAPS方向q的倍率 |
| DIRECT_Q | 用当前去噪器VJP得到u，直接对原q做倍率投影 |
| ALIGN_Q | 先把v投影到u，再把该目标投影到原q，得到连续倍率 |
| TIME | 其余4张图ALIGN逐时间步倍率的中位数，留一图时间参照 |
| CONSTANT | 其余图全30步倍率统一取中位数，不是充分调优的最强固定臂 |
| SHUFFLE | 把另一图的整条倍率曲线循环分配过来，含幅度匹配的扰动 |

DIRECT_Q不是直接使用完整u向量，三个Q臂都保留q的方向。没有完整目标向量对照，
所以本实验不能叫JAPS官方算法的完整复现，也不能判断VJP本身普遍无用。

## 5. 状态究竟如何传导到倍率

令q为原ZAPS学得的本步位移，r=y−A(m_t)为raw去噪均值的测量残差，
L为仿射观测的线性部分，当前a=sqrt(abar_t)、b²=1−abar_t。

```text
(L L^T + sigma_y² a/b² I) w = r
v = (a/b²) L^T w
u = J_m(x_t)^T v                      # 当前时间/状态的真实VJP
alpha = <v,u> / ||u||²
gamma_ALIGN = max(0, K alpha <q,u> / ||q||²)
             = max(0, K ||v||/||q|| cos(v,u) cos(q,u))
gamma_PROX  = max(0, K ||v||/||q|| cos(q,v))
```

K取本次原网格区间的条件分数位移系数；无预设上限2。
这个余弦是**同一个当前状态的向量几何**，与早期相邻随机步增量余弦不同，
也不是整条去噪轨迹的曲率或真实局部积分误差。

补洞早/中/晚各10步的ALIGN倍率中位数为`0.000119 / 0.00587 / 1.953`；
同一状态下ALIGN/PROX中位数为`0.150 / 0.222 / 0.285`。
这与双重投影会进一步缩小指导量的代数一致；早中段指导非常小，晚段测量残差/噪声比仍约5.45。
但“由哪一次抑制导致最终崩坏”尚未做独立干预，不能写成已证明的单一因果解释。
投影范数有界也不保证画质、后验正确性或合适的条件引导强度。

SR倍率早/中/晚中位数为`0.00675 / 0.1465 / 14.985`，TIME几乎复现其均值收益。
当前证据更支持阶段性的强弱分配很重要，尚不支持每图实时几何提供稳定额外收益。

## 6. 数值回退和成本不能省略

Gaussian三个几何臂累计338次CG失败（300预算耗尽+38真实残差失败）；
Motion321次（315+6）。共**659次失败**，都按原规则gamma=1回退。
Gaussian ALIGN前20步全5图回退；Motion前21步全5图回退。
另外SR DIRECT中92个q低于数值分辨阈值，同样记未解析；该臂最大倍率约280万，输出明显失稳。
不把回退1视为“状态认为无需调整”，也不在事后放宽1e-5残差准入。

A50r2研究实际新增**4872次前向、775次反向尝试且均完成**，不是免费状态观测。
每科学臂计入共享前缀后仍300前向，但ALIGN/DIRECT多VJP与大量算子求解，因此不是同计算成本。
记录的20例ALIGN后30步合计253.36秒、TIME50.25秒；C_IEEE的55.79秒含72次metrology前向和12反向，
这些是诊断臂累计记录，不能当成完整300调用部署端到端测速。

## 7. 收敛的下一步与开题边界

1. **已准备A51，先做零UNet数值准入。** 仅两个真实去模糊算子，实际t999/t319的eta，
   白噪声/算子像空间两个固定合成RHS；原CG128、重启CG128、重启CG512、fp64重启512，共32解。
   对照迭代数、算子调用、真实残差和耗时。源输入锁定；不改A50历史求解器/容差。
   [实验卡](../../experiment_cards/A51_score_cg_metrology_20261026.md)明确合成RHS不是实际去噪残差。
   通过只准入数值方案，不能称已修复真实反馈覆盖或获得重建增益。
2. 数值准入之后，下一项应是原机制的**结构分解**：完整目标向量与约束在q方向上的版本同条件对照，
   针对SR/IP分离两次投影的影响；再只扰动alpha而非整条gamma，以检查当前状态匹配。
   这是待实现的机制实验，不是本次已交付脚本，也不是新理论保证。未过不扩12图/不扫描上限救分。
3. 只有结构分解支持状态增量，才冻结规则做四任务新图确认、第二seed与噪声边界。
   固定/时间/无状态/打乱的同成本对照缺一不能称统一体系成立。
4. 步长h仍没有真实在线数值误差控制结果；只改最后30步也限制全方法NFE节省。
   当前不能把权重质量候选写成步长/预算收益，更不能据此声称开题全部实现。

可写的可靠材料：可回放基座与成本账本、不同状态信号的区别、局部代理与终局质量错位的实证、
真实数值求解失败与控制动作覆盖的关系、SR特定映射的质量候选及其多任务失败边界。
仍欠缺：独立状态贡献、可迁移的四任务机制、实时h控制和质量可比下的全成本/NFE改善。
这些缺口不能靠给当前实验增加“完成百分比”消除，也不能保证10.31前自然补齐。
