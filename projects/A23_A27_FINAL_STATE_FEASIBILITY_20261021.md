# A23–A27五轮结论：固定改进可重复，当前状态控制未获收益支持

2026-10-21。完成用户约定的最多五轮初步验证，以及用户明确重新开放的多图参数扫描。
本结论限于当前FFHQ 4×SR local_reference协议、六张开发图和十二张未用于本轮调参的确认图、
各两个相关seed、原优化后最后30次调用。没有认证作者完全复现、全十轮状态控制或跨任务泛化。

## 1. 可有把握陈述的结果

1. 固定原t319把物理修正q加倍的F，在12张确认图、24个图/seed案例上PSNR全部正向。
   平均+0.267545 dB，SSIM+.008132，LPIPS−.004609，物理loss−.036902，每方法总300 NFE。
2. 在有限开发扫描中，25个状态候选的平均PSNR全部低于原C；F在六张开发图上逐图领先。
   即使用GT事后为每图或每个seed案例在全部27配方中择优，对F的PSNR余量也为0。
   此oracle只作开发动作库的上界，不能进入线上策略或外推到所有可能动作。
3. 开发集冻结的双状态S在确认集相对C平均−.021908 dB，普通95%区间跨零，未证明增益；
   相对F平均−.289453 dB，普通95%区间完全为负，12张图均未胜F。
   可以明确说当前冻结候选缺乏竞争力，不能把S对C的小幅负均值说成已经证明普遍有害。
4. 加入方向项没有建立独立价值：S相对物理P仅+.001938 dB且区间跨零；相对幅度匹配
   物理M均值−.003585 dB，9图负向、3图PSNR相同，校正后的保守单侧上界仍跨零。
5. 上述是这套指标—动作映射和有限扫描流程的负向结论，不是所有状态指标无信息或
   整个开题绝不可能的证明。可以实现控制模块与能实现科学收益是两件事。

## 3. 扫描与冻结后究竟运行了什么

开发00020–25六图×seed1000/2000，扫描rho={0,.25,.5}、物理指标权重a={0,.25,.5,.75,1}、
引导倍率响应b={0,1}。合并rho=b=0的重复项后为25个状态候选，加C/F共27配方。
确认集在扫描结果出现前，从可访问记录未用的本地FFHQ候选池按固定随机种子抽取并冻结：
00056、00082、00085、00156、00188、00238、00308、00401、00665、00765、00780、00822。
可访问历史查重不等于全世界未用；原训练数据和该图像池范围也不能代表全部自然图像。

开发选择：

| 家族 | 冻结参数 | 开发PSNR−C | 开发保护线 |
|---|---|---:|---|
| 双状态S | rho0 / a.75 / b1 | −.007019 dB | 满足视觉/物理保护线，但PSNR为负 |
| 物理P | rho0 / a1 / b1 | −.001642 dB | 满足视觉/物理保护线，但PSNR为负 |
| 方向D | rho0 / a0 / b1 | −.020226 dB | 无合格候选，按预定规则保留为开发诊断 |

development_fallback=false只代表有满足保护线的候选，不能解释为PSNR提升。
D没有新增确认轨迹。确认六臂为C、F、S、P、M、STAGE：M取S的rho/a/b并移除方向项，
保留其物理响应幅度；STAGE用S的开发时钟中位数与逐slot几何平均gamma，不读当前图状态。
所有确认参数均冻结，没有按确认图挑参数/seed/输出。

**rho=0是关键结果：开发选出的S关闭了位置调整。** 所有确认臂因此沿用原30点评估网格，
本轮确认实际比较的是引导倍率反馈，不是已经成功的采样位置/区域调用分配。
非零rho候选仅在开发阶段被扫描，不能声称新图验证了所有移动位置参数都无效。

在有效方向可用的低噪声段t≤319，S使用

    gamma=2**(.75*e_R−.25*max(e_C,0))，并限制在[.5,2]

高噪声段gamma1。正倍率不旋转q，只改变物理修正幅度；这里的a不是对图像先验/似然损失
直接做.75/.25加权。M保留.75*e_R，移除方向扣减项；e_R/e_C仍是相对原轨迹参考的状态读数。

确认144个低噪声读数中，实际gamma仅为.893245–1.096005，中位数.977829，97点低于1、
47点高于1，方向扣减项在45点启用。虽然名义允许.5–2，当前归一化和响应使实际动作集中在1附近，
没有复现F在t319的倍率2。这个事实提示动作中心/映射与已知有效干预不一致；它是机制线索，
不能单独证明全部失败原因，也不授权自动扩大b或继续无界扫描。

## 5. 五轮对开题的结论

- A23：原R/Omega位置反馈无净收益。
- A24：匹配幅度后方向增量不稳定，恢复原槽位参数没有修复；仅留下弱网格匹配线索。
- A25：本图时钟不优于跨图互换时钟，弱匹配线索关闭。
- A26：用户授权重新开放扫描；25个状态候选开发均值都负，F逐图/逐案例领先，动作库内oracle余量0。
- A27：冻结候选在12张新图上仍未获收益；F的同预算提升可重复。

因此，当前这套R/Omega参考归一化、局部位置移动及方向抑制引导的有限参数族，不适合
作为已经验证成功的状态感知创新。指标可测、代码可运行已经完成；方向增量、个体状态
控制重建收益与效率收益均未建立。工程可实现不等于开题的科学收益已经实现。

本轮所有科学方法仍为300 NFE，只替换最后一轮，不能写节省了NFE或验证了全十轮/跨任务。
F是明确可保留的强固定工程参照；它的成功不能填入状态感知收益一栏，也不自动等于论文创新。

五轮上限已完成，不自动启动第六轮、更细a/b/rho扫描或更大确认集。
原始相邻q余弦/三步Omega不是已认证的曲率/局部误差，当前结果也不能证明其在所有目标中毫无信息。

## 6. 若另行继续研究，应改变证据链

这不是当前已解锁的新实验或服务器命令：

1. 先让动作库具有超过强固定F的机会。当前库含F且F逐开发图/案例领先，造更复杂选择器
   无法在该已测库中凭空创造收益。需要先冻结新动作定义并检验完整终局与成本。
2. 若研究F上的状态增量，应统一底座比较F、F+物理、F+双状态及幅度匹配/阶段对照。
   当前S是以倍率1为中心的轻微反馈，当前F是在一个固定阶段加倍，两者不构成已测试的
   “F再加状态”嵌套消融；不能据当前结果排除这种尚未测试的设计。
3. 若坚持开题的调用分配主线，应测试真正的同预算跨区域删点/插点。当前每原单元仍一点评估，
   尚未验证区域调用数重新分配；先看是否有实际受益动作和个体余量，再看状态能否选对。
4. 只有动作机会与状态增量通过，才值得冻结新控制器做独立确认、全流程和质量—成本曲线。

后续任何新动作、中心/阈值、符号或任务都需另行明确目标与预算，不能改名延续已关闭扫描。
本报告提供了当前方案的初步负结论和强固定正参照，不能代替尚未完成的开题主创新。
