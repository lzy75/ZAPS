## 2. 保留什么指标

物理残差R保留原定义。实际引导q的相邻余弦c与原三方向累计转向T=Omega3保留，
分别表达相邻变化和近期趋势，不再调整窗口或合成新加权分数。
同时保留u/原跨度、q RMS、clip作为上下文；q是实际修正，不称完整真实梯度。
冻结时间局部方向响应只作离线机制量，额外网络调用不能隐瞒为免费在线指标。

以后指标的资格由“能否帮助选择有益动作”判断，不由曲线是否好看、相关性是否单调判断。
下一步的动作是离线细化一个原时间区间；不是部署调度、缩放zeta或刷新同时间方向。

## 3. A3a：先保证粗细对照没有偷偷改变噪声与引导

在当前代码的DDPM fixed variance、eta=1下，记原区间t→s的后验：

    x_s = A_ts*x_t + B_ts*z_t + sigma_ts*Z + q_t

选择严格内部时间m，使log sigma_eff(m)最接近两端中点，使用模型实际alpha_bar；
平局取较小m。预声明五个区间为903→888、641→597、319→218、54→14、14→0。
按当前声明调度的本机预计算，中点分别896、619、267、28、3；服务器按实际alpha核对。
不使用s=-1，不改变999→0的正式网格。

为耦合原coarse draw Z和一份独立标准正态xi，令

    w1 = A_ms*sigma_tm/sigma_ts
    w2 = sigma_ms/sigma_ts
    Z1 = w1*Z + w2*xi
    Z2 = w2*Z - w1*xi

正交旋转保证Z1/Z2边缘为独立标准正态，且合成噪声恰为原sigma_ts*Z。
不能把同一个Z直接给两个子步；本机五区间的错误复用会使方差变成原来的约1.75–1.99倍。

引导方面，令kappa=1/(1+A_ms)。子步各采用kappa乘以同一个冻结区间引导算子G_t(z)：
G_t保留原t的alpha系数、D_t、zeta_t及实际测量算子；只允许其中的clean输入z改变。
网络在中点m用实际alpha_m计算clean，但G_t仍用原t的系数，不偷偷改成原生G_m。
冻结clean与引导场时，两子步的有效端点修正为(A_ms+1)*kappa*q_t=q_t。

这是一项明确指定的离线诊断映射，不是声称原ZAPS已经定义了连续时间引导，
也不是要求真实非线性条件下两臂实际修正向量和相同。
两段局部系数之和通常不等于1；匹配的是冻结场下传播到端点后的作用。
每段直接用.5会使原五区间的有效引导只剩约59.6%–96.5%，并非单纯细化。

本机已执行`utils/diag_ddpm_refinement_contract.py`及其测试：4项通过，
1项真实Torch核心对照因无Torch跳过，新增方法/诊断NFE均0。
五区间冻结场端点最大绝对差约3.57e-13。原始输出保存于
[代数核验证据](experiment_cards/evidence/A3a_numpy_preflight_20261020.json)。
这只证明指定映射的NumPy代数自洽，未证明实际Torch/CUDA、源工件回放或重建收益。
实际核心门控先在服务器执行，无需加载UNet或使用GPU。

## 4. A3b：用一个有上限的小实验判断细化是否值得继续

复用A2a六例和全部原五快照，不重训。每个快照：

1. C臂为原缓存下一输入，真实评估两次下一时间clean，复现原clean/q/loss/指标。
2. F臂按上节映射从相同x_t经m到相同s，在中点真实预测一次clean并更新G_t(clean)。
3. 用两份预定xi各做一条F，粗噪声Z均为原那一次，检验结论是否依赖单个桥路径。
4. 在相同s评价F的clean和物理loss。所有分支确定后才用GT评价三项质量。

中点网络每条F一次，端点评价每条F一次，C端点重复两次，故每点6次，
5点×6例×6=180诊断NFE，新方法NFE=0。原区间起点网络结果复用，不重复训练。
两个xi不是额外图像样本，统计单位仍为三个开发图像簇。

辅助噪声seed预定为322010+100*case_index+2*k+bridge_index，
case按00020_s1000至00022_s2000排序，bridge_index=0/1，k为原快照步号。
使用独立显式生成器，不改原随机历史。原Z从存档PRE RNG与缓存clean的原转移无UNet回放提取，
保存原始draw，不从已舍入的残差反推Z；需复现原29次draw和所有相关缓存状态。

先验证冻结场粗细端点、时间/参数、噪声组合、原臂回放与所有文件/RNG门控。
门控失败先修具体构造，不解释为科学负结果，不自动重跑训练。

H5的预定支持标准：至少一个原定时间层，至少2/3图的两个采样seed、两条桥路径
都满足F相对C的三指标联合非劣且物理loss不升，并至少达到一个工程收益目标：
PSNR +.1 dB，或SSIM +.001，或LPIPS -.001。
“非劣”只容许A2c既定的数值重复/漂移地板，不另开实用退化容许带；
这些工程目标不是文献定律，不在结果出来后修改。
全部五层和失败/取舍结果报告，不按GT选择桥路径、区间或输出。

- H5不通过：停止本映射/基座上的细化候选，不扫描窗口、子步数或噪声层追成功；
  不能写所有细化都无效，但本轮不继续造控制器。
- H5通过：只支持局部可干预性，先按固定规则做后续轨迹到最终输出的验证，另卡冻结。
- 平均有益但跨seed/桥不稳、或三项质量取舍：记混合，不放宽H5。

即使H5通过，也不证明c/T有预测作用。阶段汇总先比较同t、记录R/clip/幅度，
仅作描述；不在这三个图上拟合复杂阈值或把跨时间相关当增量信息。
