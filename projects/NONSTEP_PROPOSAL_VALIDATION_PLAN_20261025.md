# 开题非步长部分：结论账本与有限验证路径

日期2026-10-25。用户已关闭正则路线；本阶段固定全部30个采样点、10轮优化，
只研究状态测量和引导缩放。状态/代码/计划不等于通过的实验结果。

## 已经能回答什么

| 开题问题 | 当前证据 | 当前结论 |
| --- | --- | --- |
| 状态能否被动测量 | 单图至多图的C回放、R/cos、响应、几何记录有门控 | 能测量；可测不代表能控制画质 |
| 物理一致性是否必要、是否足够 | A36跨噪声；A38b画质约束机会诊断 | 是可解释的观测约束；低残差不保证高PSNR/低LPIPS |
| 固定调度下改引导是否有用 | A22固定脉冲；A33/A36全路径缩放 | 部分条件有明显收益，不能全归为实时状态贡献 |
| 余弦/路径转向是否已有独立价值 | A7/A10/A35、A26/27负结果；A36强TIME参照 | 现定义尚无确认增量；不是证明任何内部状态都无用 |
| 噪声正则是否值得继续 | A37/A38跨条件保护线不成立 | 本路线关闭，不继续lambda/单边组合扫描 |
| 自适应是否优于时间规则 | A36；A38b有限离线机会 | 未成立；必须将改造收益与state增量分开 |
| 多任务/多数据集是否支持 | 当前主证据FFHQ SR；历史ImageNet是local_reference | 未验证，不能由FFHQ SR收益推论 |
| 收敛/速度/免训练 | 有有限轨迹和调用计数，原ZAPS仍优化ζ/D | 不能称收敛证明、NFE节省、完全免优化 |

A38b有画质保护线时的oracle差距主要是**风险准入**，不能全部解释为
“哪张图需要哪个更强倍率”。例如sigma=.05无保护线时最强固定与oracle的
PSNR差只有约.00065 dB；group-mean画质约束允许跨图抵消。
因此下一步以“状态能否识别加强引导的最终风险”检验，而非继续放大倍率期待高分。

## 第一包：A39，本次交付的可执行实验

共同C状态、同噪声、同后续采样，测γ=.5/1.5/2单次缩放到**最终输出**的反应；
6图×2噪声，900新诊断调用。消融STAGE_NOISE、R、P、I、PI、PIG。
记录整段轨迹，但只在两个固定中心施加脉冲；不泛化为全30步最佳动作。

开题中的传导关系由此拆为四个可核对环节：

1. **状态**：R及观测响应描述欠拟合/方向可用性；clean速度转向描述内部路径稳定性。
2. **风险/收益预测**：相同t与sigma内是否还有图像差异信息；整图留出，排除时间趋势冒充state。
3. **动作**：对相同状态只改变γ，观察最终差异，避免混入采样点收益。
4. **方法效果**：冻结映射后在未用图上在线决策；本轮尚未完成此环节。

主门槛是PI的最终LPIPS变化预测优于P与STAGE_NOISE各≥10% MAE、≥4/6图改善，
PSNR等另报。失败同样给出指标定义的局部负结论，不把它包装成成功控制。
合成Torch检查在服务器强制执行；Mac不装Torch、不跑GPU。

## 第二包：在线缩放和机制消融（A39结果后锁定，尚无可执行入口）

若有风险信息候选，先锁定一个清晰的GT-free映射。状态输入只读当前/过去；
时序控制只使用训练集合的t/sigma规则；禁止同一图试所有策略再挑输出。
参照至少C、强TIME、P、I、PI。若仅P有信息，则如实使用P并报告内部通道无增量，
不硬拼PI。PIG只在其增量成立且时间成本可接受时替换方向代理。

先用未参与该映射设计的6图×2噪声×2seed，共24case；每case C完整300，
其他4臂各回放末30，最多**10080新调用**。所有臂共享原前270，终局评价。
固定seed与图像manifest后不加图直到显著；样本按image聚类，两seed不当两张图。
若A39无信息，则第二包不训练一个复杂模型强行验证；给出当前双状态证据不足结论。

同时回答：实际γ分布/饱和率、哪些步改变、物理loss与质量冲突、P/PI差异，
以及算子调用/反传和墙钟时间。每个科学臂300 NFE不代表算子成本相同。

## 第三包：跨任务与跨数据集的可迁移性（独立验证，尚未执行）

至少FFHQ与ImageNet × SR与Gaussian Deblur，构成2×2。
每格先6个未用图、同固定seed；C＋TIME＋冻结候选，最多24×(300+60)=**8640调用**。
ImageNet/模糊各自锁checkpoint、观测值域/噪声、精确H伴随与边界、合理原版ζ/D设置。
不能为了匹配历史FFHQ高分，把经验transpose称为数学伴随认证。
如算子协议改变，C与全部改造臂都要匹配，不混用旧C。

严格区分：

- 不用新任务GT修改状态→倍率映射：迁移试验。
- 任务内重新调阈值或拟合：另列校准，不能冒充零样本迁移。
- 对C变好：改造可用；对TIME变好：才是实时state有额外贡献。

这是预注册前的规模上限，不是已有代码或无条件启动；必须在第二包结论后冻结方法。
若方法在第二包失败，允许用已冻结原始响应规则做迁移边界研究，但不能写成双状态方法成功。

## 最终允许交付的结论

以最终PSNR为主，SSIM/LPIPS平均退化线仍为−.002/+ .005；逐图退化另报。
独立确认对C和TIME分别给配对image均值、区间与胜率；12图以上再做较稳定的聚类区间，
小规模6图转移只标pilot，不能做普遍泛化结论。

若验证通过，可支持“固定调度下，物理/内部状态对引导缩放的作用”这一开题子问题。
若内部指标失败，论文应如实缩小到物理状态反馈及失败机理；不能把固定倍率收益称双状态创新。
这些实验可建立非步长章节证据，但**不能证明开题中步长/采样分配创新已完成**，
也不能据此保证整篇硕士论文达到学校要求。正/负结论都必须写清适用范围和比较基线。
