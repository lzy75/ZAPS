# 状态指标阶段报告：A14/A15 与 PSNR 优先的下一步

2026-10-20。A14/A15 已完成；A16 只有实现与实验卡，未执行服务器 GPU。

A14 在六幅图、两个 seed、t14/t54 共24点全部获得可用的 IEEE FP32 响应。
其中两点复用 A13，新增220 diagnostic NFE。沿原 q 的响应大于同范数正交方向，
说明固定时间的方向敏感性有可测差异；不能据此称为 Hessian 或轨迹曲率。
完整轻量归档 cf4f68a 的24份记录 SHA、A15 全部拟合、预测及图像 MAE 已在 Mac
重算，最大绝对差1.78e−15；未在 Mac 重放原始张量/CUDA。

A15 原联合判据在两层都未通过，保留原结论：

| 时间 | PSNR增益预测 MAE 相对物理/通用基线下降 | 其他目标 | 原联合判据 |
|---|---|---|---|
| t14 | 22.25% / 10.82% | LPIPS预测通过；SSIM预测误差增加8.78% / 4.80% | 未通过 |
| t54 | 25.24% / 20.44% | SSIM和LPIPS未同时达到两个基线的10%改善 | 未通过 |

这是预测误差，不能换算成实际重建的 PSNR/SSIM/LPIPS 改变；loss 增益预测误差
增大也不等于重建物理损失增大。方向读数存在 PSNR 相关的探索性线索，但每点10次
额外调用的计量程序还没有证明在线收益或同成本收益。所有图像/结果此前已见。

用户已明确实际重建优先级：平均 PSNR 正向，平均 SSIM 降幅≤0.002、LPIPS 升幅≤0.005，
逐图退化另报。这是工程保护线，不是文献标准，不回写旧判据。
历史 A9 固定末端重估 S 相对 C 平均 PSNR +0.131696 dB、SSIM +0.003886、
LPIPS +0.002644，按新容差回顾可接受，应保留为同成本强对照。

A16 将从同一次额外预测中提取先验位移 p 和物理修正 q，以仿射测量残差线搜索
确定系数，再用 p/q 冲突约束保留一半先验投影。对比固定系数0/.5/1/2、无方向约束
的物理线搜索 L、历史 native S。新臂精度一致；不改训练或网格；GT 读取前固定所有输出。
这是新廉价状态规则，不是相邻时间步余弦，也不是 A15 敏感度的直接在线化。
六例含重复检查共新增12 diagnostic NFE；部署候选成本每例原300+1。
若只固定系数获益，只报告固定动作；若 A=L，不认定方向约束有效。

当前已证明：指标可测、固定细化/末端重估有小样本收益。尚未证明：状态规则优于
同成本固定动作、未见图像确认、扩大样本与跨任务收益。沿用旧工程里程碑估计45%，
它不代表科学成功概率。A16 失败则停止本系数区间与投影保护规则，不扫描阈值追分。
