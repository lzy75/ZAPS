## 当前究竟改变什么

原ZAPS已经逐图学习ζ和波域D。将其原引导位移记作q_k，原采样为
`x_s=DDPM(x_t,clean_t,noise)+q_k`。当前只在最后一轮30步的第25次调用处
（k24、t319→218）换成 `x_s=DDPM(...)+gamma_k*q_k`，其余全部原生。
不是每一步都已自适应，也没有改时间网格、方向q、模型权重或采样方差。

传导链：原状态与已知观测 → 五个倍率的下一时刻clean响应 → 局部协方差/
高斯条件目标 → 连续倍率提案 → 实际前向检查 → 原采样后续五步 → 离线评价。
五个小动作是0/.5/1/1.5/2。拟合的极小值可以更大，但须受噪声上界和实测检查。
gamma很大不表示物理位移同样大；真实引导RMS为gamma*RMS(q)，任务间q量级不同。

设A(x)=H((x+1)/2)，L=.5H，raw去噪均值m，观测残差r=y-A(m)。利用
`Sigma ≈ (1-alpha_s)/sqrt(alpha_s) * J_m` 的Tweedie矩关系，在两方向子空间V
测量B≈V^T Sigma V，并构造 `Sigma_P=V B V^T`。PSD/偏斜/两尺度门控仍严格。
然后构造

    m_post = m + Sigma_P L^T (L Sigma_P L^T + sigma_y^2 I)^(-1) r

PHYSICAL选物理损失最小的倍率；STATE选clean响应接近m_post的倍率，同时要求
实际物理损失不比原动作更差。ISO把B替成trace(B)/rank*I，仍在同一V子空间中。
这里是付费的近似局部矩/响应，不是完整真实后验，也不是相邻步轨迹曲率。
关系与局部高斯近似可参考[TMPD，§3.1–3.2](https://arxiv.org/html/2310.06721v3#S3)。
我们未直接实现完整TMPD，其理论保证不能移植为本方法终局PSNR保证。

协方差的作用是改变局部目标中两个方向的相对可信度及耦合，随后改变标量
gamma；它没有直接旋转实际q。因此SR/inpainting对ISO的提升说明该局部目标
值得研究，但大部分对C的增益也可由强固定倍率或纯物理控制实现。数据更支持
“任务尺度/目标几何校准”，尚不支持“各图有必须实时识别的独特倍率”。

## Nyström是什么

Nyström（奈斯特罗姆）是已有的低秩PSD矩阵近似，不是新指标名称或缩写。
原表示V B V^T把响应限制在V中；取Y≈Sigma V，可以用 `Y B^dagger Y^T`
保留已测完整列在V外的成分，仍只有至多rank2，不是恢复完整高维协方差。
参见[Tropp等，式2.5](https://papers.neurips.cc/paper/6722-fixed-rank-approximation-of-a-positive-semidefinite-matrix-from-streaming-data.pdf)。
在理想PSD条件下该公式有矩阵近似依据；实际神经网络导数和有限差分有偏差，
且更好表示测量列不必更接近最终重建风险。A43没有形成稳定主候选增量；停止
当前Nyström补全的调参救援，保留其负消融，不把它设成统一体系必要部件。

## 统一体系的边界和组成

统一指同一状态定义、同一控制公式、同一噪声/有效观测数归一化和同一保护线；
允许每任务少量开发集校准参数，测试前冻结。它不是全任务相同倍率，也不称
零调参迁移。所有任务持续保留；没有科学依据保证每图每项指标都改善。

|组成|定义与用途|当前状态|
|--|--|--|
|外在物理状态P|informative residual RMS/sigma_y，或协方差白化innovation；mask只计有效观测|已可测，不能单独保证画质|
|内部不确定性U|V内去噪响应协方差、观测侧方差/measurement-noise比|SR/inpainting目标差异明显，逐图必要性未证实|
|内部可靠性S|同t/同噪声动作响应的转向、非线性，及预测/实际改善比|先作诊断，不能改名真实轨迹曲率或预设有效|
|控制动作|固定调度下先决定gamma和是否保持原动作；先不改采样点|目前只完成固定t319单脉冲|
|预算|传感、验证、拒绝和原ZAPS300全部计费，另列墙钟时间|完整付费传感部署保守<=317，固定臂300|

原相邻步余弦在随机路径中受噪声和时间间隔影响，先前多轮没有确认独立价值。
协方差不能冒充它的成功替代品。将内在通道改进为同噪声响应可靠性/不确定性
属于开题思路的研究性修订，论文必须说明为什么修订及相应消融。

## 三包有限实验，先收敛权重子问题

|阶段|目标/固定设计|预算与解锁|
|--|--|--|
|A45，本轮已实现|同一无量纲物理/后验复合目标，lambda={0,.5,1}；旧端点复用，只新增.5。四任务分别开发校准，记录整图留出诊断|最多160新诊断，0重训；仅开发候选|
|A46，待A45后锁卡|冻结4个lambda，在6张全新图×四任务×一个seed/sigma=.05确认；对C、强任务固定、P/ISO/STATE、错配均保留。比较三指标、最差图、NFE和时间|约9–10千新调用的预算估计，实际卡另锁；原A44图不得作为新测试|
|A47，条件验证|不改lambda，检验另外噪声条件；同时设置知道task/t/sigma且有相同开发校准机会的强参照，区分噪声信息与当前图信息。先小规模，不看结果反复加图|需新的匹配基线；范围/预算在A46后锁定，不自动开启大网格|

A45复合目标为 `(1-lambda)*normalized_physical_loss + lambda*normalized_posterior_MSE`，
每项都减去原动作值并除以五动作变化量；是工程代理，不是另一套贝叶斯后验。
lambda=0/1分别是已有P/STATE；校准可用开发GT，在线动作只读状态/观测。
SR/inpainting用1、Gaussian/motion用0已经是旧端点可形成的开发组合，不把这个
已知组合冒充A45新发现。新增中点是否比最佳旧端点更均衡，单独计功。

四任务共同的最低质量目标：对匹配C的均PSNR>=+.05，SSIM>=-.002、LPIPS<=+.005，
至少80%图PSNR正向；每图退化全部单列。这些是工程筛查目标，不是学位标准。
对强固定参照，质量可非劣，但若要宣称实时状态贡献，还必须证明实际额外价值：
逐图匹配优势、跨条件更稳健或更少校准成本至少一种，并用相应匹配对照验证。
不能因为每任务都对C正向，就忽略付费传感和条件固定规则解释。

A46若无增量，不再扫lambda；A47若也没有状态操作价值，结束当前标量映射，
给出“多任务引导校准有用、实时双状态优势未证实”的结论。进一步改方向/求解器
只能另立新的机制假设，不能把它作为这条路线无上限的续命实验。

## 开题可行性与最终需要补齐什么

已核对开题PDF物理页7、10、12：原目标明确包含双指标、局部步长规划、权重与
步长协同，以及质量相当时减少NFE。来源为
`/Users/liziyue.22/Desktop/论文文档/研究生学位论文开题报告-李子玥-2240502010.pdf`。

- 固定网格下提升四任务：已有可复核正向证据，可作为论文实质章节。
- 统一可校准控制骨架：实现可行，A45只解决开发选择，不替代新图确认。
- 实时双状态独立价值：尚未成立，是A46/A47必须回答的关键问题。
- 全30步何时触发：尚未验证。需在权重路径冻结后，比较状态触发与同次数/同成本
  时间触发，并在每个新状态重新计算；不能把多个孤立脉冲收益直接相加。
- 步长/位置分配与节省NFE：仍缺严格实验，当前额外传感甚至增加调用。
  只有前述状态价值成立且成本可接受才解锁；固定NFE/固定seed也不自动保证
  Brownian路径匹配、采样无偏或收敛。
- 开题原列去噪/SR/Gaussian/inpainting，当前motion是扩展而不是已完成去噪；
  需如实标去噪未测。ImageNet按此前约定后置，不由FFHQ四任务推论。

结论：开题的“状态引导改善重建”子方向值得继续且已有动作收益；原样的完整
“双状态自适应采样并降低NFE”主张目前不能认定实现。用有限三包先明确权重
子问题，成功再开展时机/步长；不以实验编号、任意完成百分比或局部数值门控
代替创新与收敛证据，也不预先保证学位评审结论。
