## 1. 当前可以下的结论

指标可测且部分阶段结构可重复；方向指标能否帮助重建仍未建立。
已有证据足以停止“再看一次单图曲线”的验证，不足以直接制定控制律。

| 基本问题 | 现有答案 | 缺口 |
| --- | --- | --- |
| 物理残差是否描述观测一致性 | 是，限已测协议 | 不能保证感知质量，不以残差归零为目标 |
| 真实施加的引导q方向是否能测 | 是，六例可复现 | q不是已认证完整真实梯度 |
| 相邻q的转动是否等于输入敏感度 | 否，两者对象不同，代理关系未获支持 | 时间、参数和状态路径均混入相邻变化 |
| 在固定t和参数下，方向是否对输入扰动敏感 | 两尺度局部探针可读 | 该响应是否对应有益动作仍未知 |
| 简单减半引导是否可靠 | A2c原H3未获支持 | 不继续扫剂量/阶段追成功 |
| 方向刷新能否有独立作用 | 尚未做 | 必须有幅度匹配对照，且最终收益另验 |

“这条研究方向可以继续检验”和“该指标已能控制重建”是两个结论。
当前只支持前者；后续用一次有明确否定分支的实验决定是否继续方向刷新候选。

## 2. 指标固定为三个角色，不做任意加权总分

### 物理一致性R

    R_k = RMS(A(F_t(x_k))-y)/sigma_y

F_t为原实际裁剪clean估计，A为原实际测量算子，sigma_y为观测噪声。
R描述一致性，保留原定义，不能与扩散噪声sigma_eff混用。

### 过程方向T

    n_k = q_k / ||q_k||
    c_k = <n_k, n_(k-1)>
    T_k = (||n_k-n_(k-1)||+||n_(k-1)-n_(k-2)||)/(u_k-u_(k-2))

c_k是相邻实际引导向量的余弦，不是相邻图像的余弦，也不是clean增量余弦。
T就是已有Omega3，保留原三方向窗口，不引入新平滑窗口。
它测沿实际过程的累计转向/噪声坐标跨度，不称纯曲率、局部截断误差或有害振荡。
数值上直接相减单位向量，避免对接近1的余弦做acos求变化。
非零方向才计算；缺失记NA，不补成余弦1；不跨缺口拼窗口。

### 当前状态的有限尺度方向响应B

固定当前t、zeta/D、y及算子，记q0=q(x,t,i)。只使用一个预定半跨度：

    x_h = x + .5*q0
    q_h = q(x_h,t,i)
    B = ||normalize(q_h)-normalize(q0)||
    chi = B/(.5*RMS(q0))
    a0 = RMS(q0), a_h = RMS(q_h)

B范围[0,2]，对应当前修正尺度内的方向改变；chi为每单位状态RMS位移的有限差商。
这里半跨度服务于明确的两阶段修正构造，不扫描尺度。它不是eta=.01/.02探针的同一个量，
也不把有限差商命名为微分曲率/Hessian。高裁剪和幅度比a_h/a0均完整报告。
B/chi测当前冻结场，c/T描述历史过程，两者不合并、不要求单调，不强求统一正相关。
若方向范数不足或信号在重复误差内，记不可判定，不调大扰动追信号。
在线取得q_h需新增一次UNet；它不是免费的替代余弦。旧kappa探针仍只作为离线读数。

## 3. 最小新问题：方向刷新是否值得做

已有A2c改变的是沿原q的剂量。本实验改变第二次修正的方向，并用匹配幅度的对照隔离它。
以原实际下一输入x_next为锚点，原先验更新与原噪声已包含在其中，不重建或重新抽样。
三个臂都不改变t到s的跨度，也不新建中间时间点：

    C = x_next                                      # 原方法
    F = x_next - .5*q0 + .5*q_h                     # 两阶段刷新
    M = x_next - .5*q0 + .5*(a_h/a0)*q0             # 匹配幅度，保留原方向

F与M第一段相同，第二段范数相同，只改变第二段方向；因此F对M的差异可归于
该构造中的方向选择。M对C反映幅度变化；F对C反映刷新整体效果。
两段名义系数各.5，但q_h幅度可变，不能称与C实际累计向量/修正能量相同。
这不是DDPM一步拆成两个噪声时间子步，也不证明增加采样步数有益。

关键代数核验：

    RMS(F-M) = .5*a_h*B

这是恒等式，只用于检验实现，不能把B与该位移差的相关性当研究发现。
真正的结果变量是在同一原下一时间s评价三臂clean的物理loss、PSNR/SSIM/LPIPS。
F必须相对M有价值，才能排除“只是改变幅度”；也必须相对C有价值，才值得继续。
所有分支预先确定，GT只离线评估全部分支，不在线选择C/F/M。

## 5. 真正的状态感知方法还需哪两个关口

## 6. 如何压缩每轮协作

每轮交付固定四项：一张卡、一个独立脚本、一段串行命令、一份统一结果摘要。
脚本自动检查来源/已完成案例/预算；首例技术通过后自动续剩余，省去手动中间确认。
结果逐例落盘，完成案例按哈希复用，失败不覆盖；日志回贴只需状态、门控、主结果及Records。
原始POINT保存在服务器文件，按阶段一次取回轻量归档，张量留/data0。
SSH断线不等于GPU进程结束；提交后用明确运行ID查询，不能直接再提交一次。
不等待Windows完成；新入口独立运行ID/锁防止本实验的重复提交，不重跑A2a/A2c。

独立入口现已实现：`utils/diag_direction_refresh.py`；自动执行入口：`run_a2d_20261019.sh`。
启动器先跑严格无skip检查和工件审计，再一次完成全部案例。新增工件写/data0独立目录，
每点落盘并输出进展；可用`--summary-only`只读查询，不重启模型或实验。
用户启动时使用nohup和追加日志，使断开终端不直接中止任务；不需切换Codex会话。
共享核心、旧冻结卡及已有工件保持不变。生产结果仍待服务器执行，不能从本机数值检查推断。
